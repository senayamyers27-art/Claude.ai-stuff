# AI support assistant (Help widget)

Every page has a **Help** button at the bottom right. It opens a panel that:

1. **Searches the site's help answers** (`public/data/help.js`). This always works: offline, with no account, and even
   before the accounts API exists. Edit that file to add or change answers (English `q`/`a`, Spanish in `es`).
2. **Chats with an AI assistant** (Claude, by Anthropic) once the API has it switched on. The assistant answers
   questions about using the site and explains exam topics, from the same help answers plus the list of
   certifications and career tracks (`api/src/support-kb.js`, generated by `tools/build.js`, so it stays in step
   with the site).

## Switching the assistant on

It needs the accounts API running (see `BACKEND_DESIGN.md` and `CLOUDFLARE_MOVE.md`) and an Anthropic API key.

1. Create an API key at <https://console.anthropic.com/> → **API keys**. Add a payment method under **Billing**.
2. **Set a monthly spend limit** in the Console (**Limits**), for example $20, so costs can never run away.
3. GitHub → repository → **Settings → Secrets and variables → Actions → New repository secret**:
   name `ANTHROPIC_API_KEY`, value the key.
4. Run **Actions → Study site API deploy → Run workflow**. `https://<your API domain>/v1/health` then shows
   `"support": true`, and the chat appears in the Help panel.

To switch it off, delete the secret on the Worker (`npx wrangler secret delete ANTHROPIC_API_KEY`) or the GitHub
secret and redeploy. The help search keeps working.

## Cost and limits

The assistant uses **Claude Opus 5.5** (`claude-opus-5-5`, $4 per million input tokens, $20 per million output
tokens) at low effort, with answers capped at 1,500 tokens. The reference text (about 3,500 tokens) is sent with prompt
caching, so after the first question in any 5 minutes it's read at a tenth of the price. A typical question and answer
costs roughly **half a cent to one cent**.

Built-in limits (change them as Worker variables in `wrangler.toml` `[vars]` if you need to):

| Variable | Default | What it limits |
| --- | --- | --- |
| `SUPPORT_PER_HOUR` | 20 | Questions per visitor address per hour |
| `SUPPORT_PER_DAY` | 60 | Questions per visitor address per day |
| `SUPPORT_DAILY_LIMIT` | 1500 | Questions for the whole site per day (worst case about $15 a day) |

Conversations are limited to the last 12 messages and 1,500 characters per message. If `TURNSTILE_SECRET_KEY` is set
(the same bot check as sign-in), the first question of each chat needs the check too.

## Safety and privacy

- The API key stays on the Worker; the browser never sees it.
- **Nothing people type is stored.** The Worker keeps no transcript; the chat lives only in the visitor's browser tab
  (`sessionStorage`) and is gone when the tab closes. Anthropic's API does not train on API data; see Anthropic's
  commercial terms and privacy policy for its retention.
- The assistant is told to stay on the site, studying and IT careers; to teach security defensively (no working
  exploits, malware or evasion); not to share or ask for real exam questions; not to ask for personal details; and to
  say when it isn't sure instead of guessing. Answers are shown with a note that AI can be wrong.
- If Anthropic's safety classifiers decline a request, the API retries it on Anthropic's recommended fallback model
  (`fallbacks: "default"`); if that also declines, the visitor gets a short "I can't help with that one" message.
- Assistant replies are rendered as plain text with a small Markdown subset (bold, code, lists) and links only to the
  site's own pages (`#route`); anything else is shown as text.

## Files

- `public/assets/support.js`: the widget (search, chat, safe rendering). Loaded on the first click of **Help**.
- `public/data/help.js`: help answers, English and Spanish.
- `api/src/support.js`: `POST /v1/support/chat`, limits, the system prompt and the Claude call.
- `api/src/support-kb.js`: generated reference text. Rebuild with `node tools/build.js` after changing help answers.
- Tests: `api/test/support.test.js`, the Help checks in `tools/smoke.js`, and the chat check in `tools/accounts-e2e.js`
  (runs against a development stub, so no key or cost).
