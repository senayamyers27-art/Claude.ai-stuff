For loops over range() with start, stop and step, including negative steps and empty ranges

▶ Watch the overview video

Explain it simpler

A for loop repeats some instructions once for each item in a list of values. When you want to repeat something a set number of times, you give it range(), which hands out whole numbers one after another. You tell it where to start, where to stop and how big each step is. The most important rule is that the stop number itself is never included, like a fence you walk up to but never cross. So range(1, 5) gives 1, 2, 3, 4. To count down, the step must be negative, such as -1. If the numbers cannot possibly move from start toward stop in the direction of the step, range() gives nothing at all, and the loop quietly runs zero times.

The science fair at Juniper Ridge High School opens in ten minutes, and Amara's rocket display is supposed to count down from 10 on the big screen before the model launches. She tests it one last time. The screen stays blank, then shows the word Go. No numbers, no error, nothing in red. She had changed one thing that morning, tidying range(10, 0, -1) to the shorter range(10, 0) because the extra number looked unnecessary. The countdown worked yesterday. Now it silently skips every number. What did that small missing value really do, and why did Python not complain?

A for loop runs its body once for each item in a sequence. To repeat something a known number of times, you usually loop over range(), which produces a series of integers on demand without building a list in memory. The loop variable takes each value in turn, and you can use it inside the body. The header always has the shape for name in range(...):, followed by an indented block, and the loop ends by itself when the range has no more values.
