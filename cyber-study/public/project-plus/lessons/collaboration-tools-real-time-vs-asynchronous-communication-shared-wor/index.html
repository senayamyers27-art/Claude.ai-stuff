CompTIA Project+ PK0-005 · Domain 3: Tools and documentation

Collaboration tools: real-time vs asynchronous communication, shared workspaces, file sharing and document version control

▶ Watch the overview video

Last reviewed October 7, 2026 · Leer en español

Explain it simpler

Collaboration tools help people work together, especially when they are not in the same room. Some tools are real time, meaning everyone is there at the same moment, like a phone or video call. These are good for quick back-and-forth and hard conversations. Other tools are asynchronous, meaning people join in when it suits them, like email or comments on a shared document. These are good across time zones and leave a written record. Shared folders keep files in one place. Version control keeps track of every change to a file, so everyone knows which copy is the latest and can go back to an older one. It is like a family shopping list on the fridge: one list, everyone adds to it, no one is guessing which scrap of paper is current.

The cloud migration team at Brightwater Logistics spans three cities and two continents. On Monday you discover that the database team has been building against version 3 of the design document, which was emailed in March, while the network team is working from version 5 in the shared folder. A key decision about firewall rules was made on a late-night video call that half the team could not attend, and nobody wrote it down. Meanwhile, a contractor has posted the network diagram in a public link to share it faster. The tools are all there, so why is everyone confused, and which tool should carry which kind of conversation?

Modern project teams are often spread across offices, homes and time zones, so collaboration tools are central to getting work done. The Project+ exam groups these tools by how they are used rather than by product names, so focus on the categories: real-time communication, asynchronous communication, shared workspaces and file sharing, and document version control. The skill being tested is choosing the right tool for the situation.
