Just-in-time access and privileged access management

▶ Watch the overview video

Last reviewed October 7, 2026 · Leer en español

Explain it simpler

Some accounts have super powers: they can change any setting, read any file or create new users. These are privileged accounts, and attackers want them more than anything. Privileged access management, or PAM, is a set of tools and habits for keeping those powers locked up. Passwords for admin accounts go into a secure vault, get changed after every use, and every admin session is recorded. Just-in-time access goes further: nobody keeps admin powers all the time. When an engineer needs to fix something, they ask, get approved, and receive the powers for a short time, after which the powers disappear. It is like a bank vault that opens only with approval, for a set time, with a camera running.

Your first week as security manager at Copperfield Outfitters, a fast-growing online retailer. You pull the list of owners on the production cloud account: twelve engineers, all permanent, several of whom check email and browse the web from the same accounts. A backup service account has had domain administrator rights for six years with the same password. There is an 'emergency' account whose password is in a shared document. Nobody has been breached yet, as far as anyone knows. If one engineer clicks the wrong link tomorrow, how much of the company could an attacker control by lunchtime?

Privileged accounts, such as domain administrators, root, database administrators, cloud owners and service accounts with broad rights, are the keys attackers want most. With them an intruder can disable defenses, create backdoor accounts, read any data and erase evidence. Privileged access management (PAM) is the set of processes and tools that discovers, secures, limits and monitors these accounts. Just-in-time access is one of its most effective techniques. PAM matters to auditors as well as defenders, because regulations and frameworks commonly require evidence that privileged use is approved, limited and reviewed.
