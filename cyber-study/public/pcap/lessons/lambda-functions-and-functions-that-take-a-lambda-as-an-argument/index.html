Lambda functions and functions that take a lambda as an argument

▶ Watch the overview video

Last reviewed October 7, 2026 · Leer en español

Explain it simpler

A lambda is a tiny function you can write in one line without giving it a name. lambda x: x * 2 means "take x and give back x times two." It is the same as writing a normal two-line function, just shorter. The main reason to use one is to hand a small rule to another function. When you sort a list of people by age, sorted() needs to know "what should I compare?", and you can hand it the rule lambda p: p.age. It is like giving a helper a sticky note with a short instruction on it instead of writing a whole manual. The helper reads the note for each item and does what it says.

Ines runs the volunteer schedule for Cedar Hollow Food Pantry, and her Python script prints the list of volunteers sorted alphabetically. She wants it sorted by the number of hours each person has signed up for instead, and she has found a line in a colleague's notes: sorted(volunteers, key=lambda v: v[2]). It works, but she has no idea why. There is no def, no function name, and no return, yet something is clearly being called for each volunteer. On the exam you will be asked to trace exactly this kind of line. What is a lambda, and what does sorted() do with it?

A lambda is a small anonymous function written as an expression: lambda parameters: expression. The text lambda x: x * 2 creates a function that takes one argument and returns it doubled. It behaves like def double(x): return x * 2, but it has no name of its own and it fits anywhere an expression is allowed, such as an argument to another function, an item in a list, or a value returned from a function. The word anonymous simply means the function object is not bound to a name by the definition itself.
