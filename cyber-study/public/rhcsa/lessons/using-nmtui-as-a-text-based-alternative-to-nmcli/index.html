Red Hat Certified System Administrator EX200 (RHEL 10) · Domain 8: Manage basic networking

Using nmtui as a text-based alternative to nmcli

▶ Watch the overview video

Last reviewed October 7, 2026 · Leer en español

Explain it simpler

NetworkManager is the part of RHEL that keeps track of network settings such as the computer's address, its gateway (the door out to other networks) and its DNS servers (the address book for names). There are two common ways to talk to it from a terminal. nmcli is a typed command where you must know exact setting names. nmtui is a simple menu that runs inside the terminal: you move with the arrow keys and Tab, fill in labeled boxes and press Enter. Both write the same settings files. The catch is that saving a change in nmtui is like writing a new address on a form: it is stored, but the network card keeps using the old one until you switch the connection off and on again.

You are forty minutes into a practice exam at the Cedar Valley Library training lab. The task reads: give server2 the static address 172.25.250.11/24, gateway 172.25.250.254, DNS server 172.25.250.254, and hostname server2.lab.example. You start typing an nmcli command, pause, and cannot remember whether the property is ipv4.address or ipv4.addresses. Beside you, Rosa from the evening class opens a blue menu screen, tabs through labeled boxes, and is finished before you have checked the man page. But when the instructor tests her machine, it still answers on the old address. What did the menu save, and what did it not do?

nmtui, short for NetworkManager text user interface, is a menu-driven program for the same everyday tasks you perform with nmcli. It runs in any terminal, including the exam's remote console, and you navigate it with the arrow keys, Tab, Enter and the space bar. Because both tools are clients of NetworkManager, they read and write the same connection profiles, stored as keyfiles under /etc/NetworkManager/system-connections/. Under exam time pressure, many people find nmtui quicker and less error-prone for one-off changes, because every field is labeled and you never need to recall exact property names such as ipv4.addresses or ipv4.method. The command comes from the NetworkManager-tui package, which may not be installed by default, so be ready to run dnf install -y NetworkManager-tui.
