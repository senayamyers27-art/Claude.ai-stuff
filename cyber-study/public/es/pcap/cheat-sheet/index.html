Dominio 1: Modules and Packages (12%)

Consejos para el examen

  • Pregúntate qué nombres agrega cada línea. import m as x define solo x, nunca m; from m import f define solo f, nunca m. Muchas opciones de respuesta que parecen correctas fallan con NameError justamente por esto.
  • Con import a.b.c simple debes usar el prefijo completo a.b.c, y el último componente debe ser un módulo, no una función ni una clase. Las preguntas suelen ofrecer import a.b.func como respuesta incorrecta tentadora.
  • dir(x) necesita un nombre que realmente exista. Después de from math import sqrt, dir(math) genera NameError; después de import math as m, debes llamar a dir(m).
  • append() revisa la carpeta nueva al final, insert(0, ...) la revisa primero, y ningún cambio sobrevive más allá de la ejecución actual. La modificación debe ir antes del import que depende de ella.
  • Prueba con negativos: floor(-2.5) es -3, pero trunc(-2.5) y ceil(-2.5) son -2. Recuerda también que sqrt y hypot siempre devuelven floats, así que sqrt(16) imprime 4.0, no 4.
  • random() puede devolver 0.0 pero nunca 1.0, y sample() genera ValueError si k supera el tamaño de la población. Misma semilla más mismas llamadas es igual a misma salida.
  • platform.version() es la versión del sistema operativo, no la de Python. python_version_tuple() devuelve cadenas, no enteros, y processor() puede devolver legítimamente una cadena vacía.
  • Las importaciones siguen ejecutando todo el código de nivel superior no protegido. Solo las sentencias dentro del bloque if __name__ == '__main__': se omiten cuando el archivo se importa.
  • El script principal se compila pero no se guarda en caché; solo los módulos importados reciben archivos .pyc. La caché acelera la carga, no la ejecución.
  • Un guion bajo inicial solo afecta a from module import *. Las importaciones explícitas y el acceso calificado como module._name siguen funcionando, así que es una convención y no privacidad real.

Dominio 2: Exceptions (14%)

Consejos para el examen

  • Solo se ejecuta la primera rama coincidente, y una superclase listada primero se traga a sus subclases. Cuando dos ramas podrían coincidir, gana la que está más arriba.
  • La tupla necesita paréntesis: except (A, B): es la forma que espera el examen, y except A, B: es el distractor clásico. Agrega as e cuando necesites saber qué clase se atrapó.
  • print(e) muestra el mensaje; print(e.args) muestra una tupla, que con un argumento se ve como ('message',). Sin argumentos, args es () y str(e) está vacío. La variable de as desaparece después del bloque except.
  • else significa que no ocurrió ninguna excepción; finally significa siempre. Si ocurre una excepción, else se omite aunque la excepción se haya manejado. El orden es try, except, else, finally.
  • Conoce los padres: ZeroDivisionError bajo ArithmeticError, IndexError y KeyError bajo LookupError, ModuleNotFoundError bajo ImportError, y KeyboardInterrupt directamente bajo BaseException, no bajo Exception.
  • raise ValueError y raise ValueError() funcionan las dos; la forma con la clase crea una instancia con args vacío. Un raise sin argumentos solo es válido mientras se maneja una excepción; en otro lugar causa RuntimeError.
  • assert (cond, 'msg') con paréntesis es una tupla no vacía y siempre pasa. Nunca confíes en assert para validar entradas, porque -O lo elimina. Un assert fallido lanza AssertionError con el mensaje como argumento.
  • KeyboardInterrupt, SystemExit y GeneratorExit heredan de BaseException, no de Exception. Solo un except sin clase, except BaseException o la clase específica los atrapan.
  • Las excepciones personalizadas deben derivar de Exception. Si sobrescribes __init__, pasa un mensaje a super().__init__() para que args y str(e) sigan teniendo sentido, y guarda los datos como atributos para que los manejadores los lean.

Términos clave

Un objeto que representa un error o un evento inusual que interrumpe el flujo normal.

Un manejador que se ejecuta cuando la excepción lanzada coincide con su clase o con una subclase de ella.

El movimiento de una excepción no manejada hacia afuera, hacia las sentencias try que la rodean y las funciones que hicieron la llamada.

Un except sin clase que lo atrapa todo; debe ser la última rama.

El informe que se imprime cuando una excepción no se maneja, con las llamadas involucradas y la clase y el mensaje de la excepción.
Tupla de excepciones
Una lista de clases entre paréntesis en una sola cláusula except; la rama coincide con cualquiera de ellas.
Enlace con as
La forma except ... as nombre, que da al manejador acceso al objeto de excepción.
Coincidencia por subclase
Una rama except también atrapa instancias de subclases de las clases listadas.
e.args
La tupla de argumentos con los que se creó un objeto de excepción, que a menudo contiene su mensaje.
Exception instance (instancia de excepción)
El objeto que se crea cuando se lanza una excepción; except ... as name lo enlaza a un nombre.

Una tupla que contiene los argumentos pasados al constructor de la excepción; está vacía si no se dio ninguno.
str(e)
El mensaje imprimible de una excepción, derivado de args: el único argumento, una cadena vacía o la tupla completa.

El nombre de la clase de la excepción atrapada como cadena, útil para el registro.

Se ejecuta solo cuando el bloque try termina sin lanzar una excepción; requiere al menos una rama except.
finally branch (rama finally)
Se ejecuta cada vez que se sale de la sentencia try, ya sea normalmente, por una excepción o por return, break o continue.
Clean-up code (código de limpieza)
Sentencias que liberan recursos, como cerrar archivos o conexiones, y que por eso van en finally o en una sentencia with.
Propagation (propagación)
Una excepción no manejada que sigue hacia afuera, hacia quien llama, después de que se ejecutó finally.
BaseException
La raíz de todas las excepciones integradas, incluidas señales que no son errores, como KeyboardInterrupt y SystemExit.
Exception
La clase base de los errores comunes y de las excepciones definidas por el usuario.
ArithmeticError
Padre de ZeroDivisionError, OverflowError y FloatingPointError.
LookupError
Padre de IndexError y KeyError; se lanza cuando una clave o un índice no es válido.

Función integrada que devuelve True si una clase hereda, directa o indirectamente, de otra.
raise
Sentencia que señala una excepción, dada una clase o una instancia derivada de BaseException.
Bare raise (raise sin argumentos)
raise sin operando dentro de una rama except; relanza la excepción actual sin cambios.
Exception chaining (encadenamiento de excepciones)
Vincular una nueva excepción con la que la causó, automáticamente como contexto o de forma explícita con raise ... from.
assert
Sentencia que lanza AssertionError cuando su condición es falsa y no hace nada cuando es verdadera.
AssertionError
La excepción que lanza un assert fallido; subclase directa de Exception.
-O option (opción -O)
Bandera del intérprete que elimina las sentencias assert para que nunca se evalúen.
Truth value (valor de verdad)
Si Python trata una expresión como verdadera o falsa; 0, None y los contenedores vacíos son falsos.
KeyboardInterrupt
Se lanza cuando el usuario presiona la tecla de interrupción (Ctrl+C); hereda directamente de BaseException.
SystemExit
La lanza sys.exit(); su atributo code contiene el código de salida, y hereda directamente de BaseException.
except Exception
Un manejador amplio para errores comunes que excluye deliberadamente las señales de salida e interrupción.
Custom exception (excepción personalizada)
Una clase definida por el usuario que hereda de Exception y que se lanza y atrapa como las excepciones integradas.
Exception hierarchy (jerarquía de excepciones)
Un conjunto de clases de excepción relacionadas donde una clase base permite que quien llama atrape todo el grupo.
super().__init__()
Llamada al constructor del padre, que establece args y, por lo tanto, el mensaje impreso.
__str__()
Método que devuelve la forma imprimible de un objeto; sobrescribirlo controla lo que muestra print(e).

Dominio 3: Strings (18%)

Consejos para el examen

  • ASCII es un subconjunto de Unicode; UTF-8 es una codificación de Unicode, no un juego de caracteres aparte. Una str de Python cuenta code points, así que len('é') es 1 aunque ocupe 2 bytes en UTF-8. Recuerda 32, 48, 65 y 97 para el espacio, '0', 'A' y 'a'.
  • ord() necesita exactamente un carácter; si no, TypeError. chr() necesita un int en el rango de 0 a 0x10FFFF; si no, ValueError. Recuerda 'A' = 65, 'a' = 97, '0' = 48 y espacio = 32.
  • Cada secuencia de escape cuenta como un carácter: len('\n') es 1 y len('\\') es 1. En una raw string, len(r'\n') es 2. Cuidado con los escapes accidentales en las rutas de Windows.
  • Indexar fuera de rango lanza IndexError; rebanar fuera de rango solo recorta. Con un paso negativo, el inicio debe ser mayor que el fin o el resultado queda vacío. Un paso de 0 lanza ValueError.
  • Cualquier sentencia que asigne a s[i] o a s[a:b], o que borre s[i], lanza TypeError con cadenas. Los métodos devuelven cadenas nuevas; si el resultado no se asigna, se pierde.
  • En las cadenas, in busca una subcadena contigua y distingue entre mayúsculas y minúsculas, y la cadena vacía siempre está en cualquier cadena. Mezclar tipos, como 3 in 'a3', lanza TypeError.
  • '5' == 5 es False sin error, pero '5' < 5 lanza TypeError. Al ordenar cadenas, las mayúsculas van antes que las minúsculas y '10' < '9'.
  • Todos los métodos is devuelven False para la cadena vacía. isdigit() rechaza '-' y '.', e isupper() necesita al menos una letra mayúscula y ninguna minúscula, ignorando dígitos y símbolos.
  • find devuelve -1 cuando falla; index lanza ValueError. Y join se llama sobre el separador: ', '.join(items), nunca items.join(', ').
  • sorted('abc') devuelve una lista, no una cadena; únela con join para obtener una cadena. list.sort() devuelve None, así que nunca asignes ni imprimas su resultado esperando una lista.

Que tiene un valor hash fijo, algo que la inmutabilidad hace posible y que los diccionarios exigen para las claves.

Comprueba si dos nombres se refieren al mismo objeto; sirve para ver si un nombre ahora se refiere a un objeto nuevo.

Subcadena (substring)
Una serie de caracteres contiguos que aparece, en orden, dentro de una cadena más larga.

Inmutable
Que no se puede cambiar después de crearse; las operaciones con cadenas siempre producen cadenas nuevas.

Dominio 4: Object-Oriented Programming (34%)

Consejos para el examen

  • Una clase es el plano; un objeto es una instancia construida a partir de él. Las subclases heredan todo de las superclases y pueden sobrescribirlo, y toda clase hereda de object.
  • obj.x = value siempre crea o actualiza una variable de instancia; nunca cambia la variable de clase. Cambia los datos compartidos a través del nombre de la clase.
  • El __dict__ de una instancia contiene solo los atributos asignados en esa instancia. Las variables de clase y los métodos viven en el __dict__ de la clase, y los nombres heredados no aparecen en el __dict__ de una subclase.
  • Dentro de la clase C, __x se convierte en _C__x. Fuera de la clase, obj.__x no se altera y falla (o crea un atributo separado si se asigna). Los nombres dunder como __init__ nunca se alteran.
  • Todo método de instancia necesita self como primer parámetro, y obj.m(a) pasa obj automáticamente. Una segunda definición de __init__ reemplaza a la primera; Python no tiene sobrecarga de constructores.
  • __name__ y __bases__ pertenecen a las clases; en una instancia, pasa primero por type(obj) u obj.__class__. __bases__ enumera solo los padres directos, en una tupla.
  • super().method(args) no recibe self; ClassName.method(self, args) sí. Si una subclase sobrescribe __init__ sin llamar a super().__init__(), faltarán los atributos del padre.
  • En un diamante, el ancestro común va después de todas sus subclases en el MRO. Escribir una superclase antes que una de sus propias subclases en las bases lanza TypeError cuando se define la clase, no cuando se llama a un método. Revisa NombreDeClase.__mro__ si puedes ejecutar código.
  • issubclass(C, C) es True. isinstance también coincide con las superclases y acepta una tupla de clases. a == b compara valores; a is b compara identidad, y b = a no crea ninguna copia. Usa is None, nunca == None.
  • print(obj) llama a obj.__str__(); sin una sobrescritura obtienes el texto predeterminado <... object at 0x...>. __str__ debe devolver una cadena. Las llamadas polimórficas ejecutan el método de la clase real del objeto, incluso cuando se llaman desde código de la superclase.

Términos clave

Clase (class)
Un plano que define los atributos y métodos que tendrán sus objetos.
Objeto (instancia)
Un valor concreto creado a partir de una clase, con su propio estado.
Atributo (attribute)
Un valor con nombre que pertenece a un objeto o a una clase, al que se accede con notación de punto.
Método (method)
Una función definida dentro de una clase que opera sobre sus objetos.
Encapsulación (encapsulation)
Agrupar los datos con los métodos que los gestionan y restringir el acceso directo a esos datos.
Superclase / subclase
Una clase padre y una clase que hereda de ella, especializándola o ampliándola.
Variable de instancia (instance variable)
Un atributo guardado en un objeto, normalmente asignado como self.name en __init__.
Variable de clase (class variable)
Un atributo definido en el cuerpo de la clase y compartido por todas las instancias.
Shadowing (ocultamiento)
Un atributo de instancia con el mismo nombre que oculta un atributo de clase cuando se accede a través de esa instancia.
Búsqueda de atributos (attribute lookup)
El orden de búsqueda al leer obj.attr: la instancia, luego su clase y luego las superclases.
__dict__
El diccionario (o mapping proxy, en el caso de las clases) que contiene los atributos propios de un objeto.
mappingproxy
El tipo de mapeo de solo lectura que se usa para el __dict__ de una clase.
vars()
Función integrada que devuelve el __dict__ de un objeto.
Introspección (introspection)
Examinar los atributos y el tipo de un objeto mientras el programa se ejecuta.
Atributo privado (private attribute)
Un atributo cuyo nombre empieza con dos guiones bajos (y no termina con dos), sujeto a name mangling.
Name mangling (alteración de nombres)
Reescribir __name dentro de una clase como _ClassName__name para evitar conflictos.
Convención del guion bajo simple
Un _ inicial marca un nombre como interno, pero no se hace cumplir de ninguna forma.
Dunder name (nombre dunder)
Un nombre que empieza y termina con dos guiones bajos, como __init__; nunca se altera.
self
El nombre convencional del primer parámetro de un método, que recibe la instancia.
__init__
El inicializador que se ejecuta automáticamente al crear un objeto y asigna sus atributos.
Argumento predeterminado (default argument)
Un valor de parámetro que se usa cuando quien llama no proporciona uno.
Argumento con nombre (keyword argument)
Un argumento que se pasa como name=value, lo que permite saltarse valores predeterminados anteriores.
hasattr()
Devuelve True si un objeto tiene, o puede alcanzar, un atributo con el nombre indicado como cadena.
__class__
Un atributo de todo objeto que se refiere a la clase a partir de la cual se creó.
__bases__
Una tupla con las superclases directas de una clase, disponible solo en las clases.
__module__
El nombre del módulo en el que se definió una clase, como cadena.
Herencia simple (single inheritance)
Una clase con exactamente una superclase directa.
Herencia múltiple (multiple inheritance)
Una clase que enumera dos o más superclases directas.
Overriding (sobrescritura)
Definir en una subclase un método con el mismo nombre que uno de una superclase, reemplazándolo para la subclase.
super()
Devuelve un proxy que encuentra la versión de un método de la siguiente clase en el orden de resolución de métodos.
Mixin
Una clase pequeña que añade una sola capacidad y se combina con otras clases mediante herencia múltiple.
MRO
Method resolution order (orden de resolución de métodos): la lista ordenada de clases en la que Python busca un atributo, usando la primera coincidencia.
Diamond problem (problema del diamante)
Una jerarquía en la que dos clases padre comparten un ancestro común, lo que plantea la cuestión del orden de búsqueda y de las visitas duplicadas.
C3 linearization (linealización C3)
El algoritmo que usa Python para calcular un MRO coherente que respeta el hijo antes que el padre y el orden de las bases de izquierda a derecha.
__mro__
Un atributo de clase que contiene su MRO como una tupla de objetos de clase; mro() devuelve las mismas clases como lista.
isinstance()
Devuelve True si un objeto es una instancia de una clase, de cualquiera de sus subclases o de cualquier clase de una tupla de clases.
issubclass()
Devuelve True si una clase es la misma que otra clase, o deriva de ella directa o indirectamente.
Identity (identidad, is)
Si dos referencias apuntan al mismo objeto en memoria.
Equality (igualdad, ==)
Si dos objetos tienen valores iguales según el método __eq__ de su tipo.
id()
Función integrada que devuelve un número que identifica a un objeto durante su tiempo de vida.
Polymorphism (polimorfismo)
La capacidad de distintas clases de responder a la misma llamada a un método cada una a su manera.
Method overriding (sobrescritura de métodos)
Definir en una subclase un método con el mismo nombre que uno de su superclase, reemplazándolo para los objetos de la subclase.
Duck typing (tipado de pato)
Usar cualquier objeto que proporcione los métodos necesarios, sin importar su clase.
__str__()
Método especial que devuelve la forma legible de un objeto como cadena, usado por print() y str().
__repr__()
Método especial que devuelve una representación orientada al desarrollador, usada en el intérprete interactivo y dentro de contenedores.

Dominio 5: Miscellaneous (22%)

Consejos para el examen

  • Con varias cláusulas for, el bucle de más a la izquierda es el externo. Un if al final filtra (no admite else); un if ... else al principio transforma cada elemento. Construye cuadrículas con una comprensión anidada, nunca multiplicando una lista que contiene una lista.
  • El cuerpo de una lambda es una sola expresión con return implícito; sin sentencias y sin la palabra clave return. Cuando una función recibe una lambda, síguela sustituyendo cada argumento en la expresión de la lambda. Las funciones clave eligen el valor de comparación, pero se devuelven los elementos originales.
  • map y filter devuelven iteradores, no listas, y cada uno se puede consumir una sola vez. Un segundo list() del mismo objeto da []. filter(None, items) conserva solo los elementos truthy. map con varios iterables se detiene en el más corto.
  • Los closures recuerdan variables, no instantáneas de valores. Las funciones creadas en un bucle ven todas el valor final de la variable del bucle, a menos que la vincules con un argumento por defecto. Para cambiar una variable envolvente, declárala nonlocal.
  • Llamar a una función generadora no ejecuta nada de su cuerpo hasta el primer next(). Después del último yield, next() lanza StopIteration, que los bucles for absorben en silencio. Los generadores son de un solo uso, no tienen len() y no se pueden indexar.
  • 'w' borra el contenido existente en el momento en que se abre el archivo, 'a' lo conserva, 'x' falla si el archivo existe y 'r' falla si no existe. El signo más nunca cambia esas reglas. El modo texto da str y el modo binario da bytes.
  • print() escribe en sys.stdout por defecto e input() lee de sys.stdin; sys.stderr está separado para que los errores sobrevivan a la redirección de la salida normal. Los tres están abiertos antes de que empiece tu programa. write() no añade salto de línea y devuelve un conteo.
  • El final del archivo se indica con un resultado vacío ('' o b''), no con una excepción; una línea en blanco es '\n'. write() nunca añade saltos de línea y devuelve un conteo. readinto() necesita un bytearray y un archivo en modo binario. Usa with para que los archivos siempre se cierren.
  • Compara e.errno con las constantes del módulo errno, nunca con números sueltos. ENOENT va con FileNotFoundError, EACCES con PermissionError y EEXIST con FileExistsError, todas subclases de OSError. Usa strerror u os.strerror() para obtener mensajes legibles.

Términos clave

List comprehension (comprensión de lista)
Una expresión entre corchetes que construye una lista recorriendo un iterable.
Filter clause (cláusula de filtro)
Un if al final de una comprensión que incluye solo los elementos que cumplen una condición; no tiene else.
Conditional expression (expresión condicional)
A if condición else B, colocada al principio para elegir un valor para cada elemento.
Nested comprehension (comprensión anidada)
Una comprensión dentro de otra, usada para construir listas de listas, como las cuadrículas.
Generator expression (expresión generadora)
Sintaxis de comprensión entre paréntesis que produce valores de forma perezosa en lugar de construir una lista.
Lambda
Una función anónima definida por una sola expresión, cuyo valor devuelve automáticamente.
Higher-order function (función de orden superior)
Una función que recibe otra función como argumento o que devuelve una.
key function (función clave)
Una función que se pasa a sorted(), list.sort(), min() o max() para calcular el valor de comparación de cada elemento.
Anonymous function (función anónima)
Un objeto función al que su definición no le da un nombre.
map()
Devuelve un iterador que aplica una función a cada elemento de uno o más iterables y se detiene en el más corto.
filter()
Devuelve un iterador que entrega los elementos originales para los que una función devuelve un valor verdadero.
Iterator (iterador)
Un objeto que produce valores uno a la vez con next(); una vez agotado, no entrega nada más.
Lazy evaluation (evaluación perezosa)
Calcular los valores solo cuando se piden, en lugar de todos a la vez.
Truthy (verdadero en contexto booleano)
Un valor que se trata como verdadero en una condición; filter(None, ...) conserva solo los elementos truthy.
Closure (clausura)
Una función interna que conserva el acceso a las variables del ámbito de la función envolvente después de que esa función termina.
Enclosing scope (ámbito envolvente)
El ámbito local de una función externa, visible para las funciones anidadas dentro de ella.
nonlocal
Declaración que permite a una función interna volver a vincular una variable de la función envolvente más cercana.
Late binding (enlace tardío)
Consultar las variables libres de un closure cuando se llama, no cuando se crea.
LEGB rule (regla LEGB)
El orden de búsqueda de nombres de Python: Local, Enclosing (envolvente), Global, Built-in (integrado).
Generator function (función generadora)
Una función que contiene yield; llamarla devuelve un objeto generador sin ejecutar el cuerpo.
yield
Produce un valor y pausa el generador, conservando su estado local hasta la siguiente petición.
next()
Función integrada que pide a un iterador su siguiente valor; con un segundo argumento, devuelve ese valor por defecto en lugar de lanzar StopIteration.
StopIteration
Excepción que se lanza cuando un iterador no tiene más valores; los bucles for y list() la manejan automáticamente.
'r' mode (modo 'r')
Modo de lectura, el predeterminado: el archivo debe existir y el contenido se conserva.
'w' mode (modo 'w')
Modo de escritura: crea el archivo o trunca uno existente a longitud cero al abrirlo.
'a' mode (modo 'a')
Modo de añadir (append): crea el archivo si hace falta, conserva el contenido y las escrituras siempre van al final.
'x' mode (modo 'x')
Creación exclusiva: crea un archivo nuevo y falla con FileExistsError si ya existe.
Text mode (modo texto)
Modo ('t', el predeterminado) que decodifica bytes a str usando una codificación y traduce los finales de línea.
Binary mode (modo binario)
Modo ('b') que lee y escribe bytes sin procesar, sin decodificación ni traducción.
Stream (flujo)
Una corriente ordenada de datos que un programa lee o escribe.
Stream handle (manejador de flujo)
El objeto devuelto por open(), o proporcionado por sys, mediante el cual se usa un flujo.
sys.stdin
La entrada estándar, que lee input() y que por defecto está conectada al teclado.
sys.stdout
La salida estándar, el destino predeterminado de print().
sys.stderr
El error estándar, un flujo de salida separado para mensajes de error, diagnósticos y tracebacks.
read()
Lee el resto del archivo, o como máximo n caracteres o bytes si recibe un argumento; devuelve un resultado vacío al final del archivo.
readline()
Lee una línea incluido su salto de línea; devuelve una cadena vacía al final del archivo.
readlines()
Devuelve una lista con todas las líneas restantes, cada una con su salto de línea.
readinto()
Llena un bytearray existente a partir de un archivo binario y devuelve el número de bytes leídos, 0 al final del archivo.
with statement (sentencia with)
Un bloque de gestor de contexto que cierra el archivo automáticamente cuando termina, incluso después de una excepción.
errno attribute (atributo errno)
El código de error del sistema operativo guardado en una instancia de OSError.
errno module (módulo errno)
Módulo estándar que define constantes con nombre, como ENOENT y EACCES, para los códigos de error.
ENOENT
Código de error que significa que no existe el archivo o directorio; corresponde a FileNotFoundError.
EACCES
Código de error que significa permiso denegado; corresponde a PermissionError.
strerror
Atributo de OSError que contiene el mensaje legible del código; os.strerror(code) devuelve el mismo tipo de texto.
