Dominio 1: Computer programming and Python fundamentals (18%)

Consejos para el examen

  • Las preguntas del examen suelen pedir qué tipo de error produce un fragmento. Los paréntesis faltantes, la mala indentación o las palabras clave fuera de lugar son errores de sintaxis detectados antes de ejecutar nada; el código válido que hace algo imposible es un error en tiempo de ejecución, que solo aparece cuando se llega a esa línea.
  • True, False y None son palabras clave con mayúscula inicial; true en minúsculas es solo un nombre no definido. Un # entre comillas no es un comentario, y un comentario solo nunca puede ser el cuerpo de un bloque.
  • Fíjate en el punto decimal y en la e: 5 es int, 5.0 y 5. son float, 5e0 es float. Y "5" entre comillas es un str, sin importar cómo se vea.
  • El prefijo octal es un cero más la letra o (0o), no dos ceros, y un cero inicial simple como en 017 es un SyntaxError en Python 3. Recuerda que bin(), oct() y hex() devuelven cadenas, mientras que los literales con prefijo son ints que se imprimen en decimal.
  • Válido y convencional son preguntas distintas. Las preguntas del examen pueden pedir qué nombres no son válidos (dígito al inicio, guion, espacio, palabra clave) frente a cuáles incumplen PEP 8 pero igual se ejecutan (MyVariable para una variable, por ejemplo).
  • Dos trampas clásicas: / siempre devuelve un float, y // redondea hacia menos infinito, así que -7 // 2 es -4. Revisa dos veces cada pregunta de división entera o módulo con negativos.
  • Prepárate para una pregunta en la que se suma un número a una cadena. "3" + 4 es un TypeError, "3" * 4 es "3333", y x *= 2 + 1 multiplica por 3, porque todo el lado derecho se evalúa primero.
  • Memoriza las dos excepciones: ** se asocia de derecha a izquierda, y ** le gana a un menos unario a su izquierda. Todo lo demás en el mismo nivel se ejecuta de izquierda a derecha, así que %, *, // y / se aplican estrictamente en el orden de lectura.
  • La forma más rápida de resolver las preguntas con ~ es la fórmula ~x = -x - 1. Para &, | y ^, convierte siempre a binario y alinea las columnas; adivinar a partir de los valores decimales es donde ocurren los errores. Y ^ es XOR, nunca exponenciación.
  • Si un fragmento del examen compara sumas de floats con ==, sospecha que da False. Si llama a round() con un valor terminado en .5, recuerda el redondeo de mitades al par: round(2.5) es 2 y round(3.5) es 4.
  • int() nunca redondea; trunca hacia cero y rechaza las cadenas que contienen un punto decimal. bool() de cualquier cadena no vacía, incluso "0" o "False", es True.
  • Cuando una pregunta usa input(), supón que es una cadena hasta que veas int() o float(). Con print(), cuenta los separadores con cuidado: sep aparece solo entre argumentos, y end aparece una vez, al final de todo.

Términos clave

Source code (código fuente)
El texto del programa, legible por humanos, que escribes; en Python se guarda en un archivo .py de texto plano.
Compiler (compilador)
Un programa que traduce todo el código fuente a código máquina por adelantado y produce un ejecutable separado.
Interpreter (intérprete)
Un programa que lee y ejecuta el código fuente cada vez que este se ejecuta; CPython es el intérprete de referencia de Python.
Lexis (léxico)
El vocabulario de un lenguaje: las palabras y símbolos válidos que reconoce.
Syntax (sintaxis)
Las reglas gramaticales para combinar los elementos léxicos en instrucciones válidas.
Semantics (semántica)
Las reglas que deciden si una instrucción bien formada tiene sentido y qué significa.
REPL
El bucle interactivo de lectura, evaluación e impresión, indicado por el símbolo >>>, que ejecuta cada línea a medida que la escribes.
Statement (instrucción)
Una sola orden que el intérprete ejecuta, normalmente una por línea.
Keyword (palabra clave)
Una palabra reservada con significado fijo, como if, for o def, que no puede usarse como identificador.
Block (bloque, suite)
El grupo de instrucciones indentadas que pertenece a una línea de encabezado que termina en dos puntos.
Comment (comentario)
Texto desde # hasta el final de la línea, que el intérprete ignora.
IndentationError
La subclase de SyntaxError que se lanza cuando la indentación falta, es inesperada o es inconsistente.
Docstring (cadena de documentación)
Un literal de cadena colocado en primer lugar en un módulo o una función, que se conserva como su documentación.
Literal
Un valor escrito directamente en el código fuente, cuya forma determina su tipo.
int
El tipo entero de Python para números enteros, sin límite de tamaño fijo.
float
El tipo de Python para números con parte fraccionaria o exponente, como 2.5 o 1e-3.
Scientific notation (notación científica)
Notación de float que usa e o E para una potencia de diez, como en 6.02e23; siempre produce un float.
bool
El tipo booleano con los valores True y False, una subclase de int donde True equivale a 1 y False a 0.
str
El tipo de texto de Python, escrito entre comillas simples, dobles o triples.
None
El único valor de NoneType, que significa la ausencia de un valor.
0b prefix (prefijo 0b)
Marca un literal entero binario (base 2), que usa solo los dígitos 0 y 1.
0o prefix (prefijo 0o)
Marca un literal entero octal (base 8), que usa los dígitos del 0 al 7.
0x prefix (prefijo 0x)
Marca un literal entero hexadecimal (base 16), que usa del 0 al 9 y de la A a la F.
bin(), oct(), hex()
Funciones integradas que devuelven una representación en cadena de un entero en base 2, 8 o 16, con prefijo.
int(text, base)
Convierte una cadena de dígitos escrita en la base indicada en un int.
Bit
Un solo dígito binario, 0 o 1; un dígito hexadecimal representa cuatro bits.
Variable
Un nombre vinculado a un valor mediante asignación; el valor, no el nombre, es el que tiene un tipo.
Identifier (identificador)
Cualquier nombre que creas; puede usar letras, dígitos y guiones bajos, no debe empezar con un dígito y no debe ser una palabra clave.
Dynamic typing (tipado dinámico)
El mismo nombre puede hacer referencia a valores de distintos tipos a lo largo del tiempo, sin declaración.
PEP 8
La guía de estilo oficial de Python, que recomienda snake_case para variables y funciones, UPPER_CASE para constantes y CapWords para clases.
Shadowing a built-in (ocultar una función integrada)
Asignar un valor a un nombre integrado como list o str, lo que oculta la función original en ese ámbito.
NameError
La excepción que se lanza cuando el código usa un nombre al que no se le ha asignado nada.
True division (/) (división real)
División que siempre devuelve un float, incluso para resultados exactos como 4 / 2 = 2.0.
Floor division (//) (división entera)
División redondeada hacia abajo, hacia menos infinito; int con dos ints, float en otro caso.
Modulo (%) (módulo)
El resto que acompaña a la división entera; en Python toma el signo del divisor.
Exponentiation (**) (exponenciación)
Eleva el operando izquierdo a la potencia del operando derecho.
ZeroDivisionError
La excepción que se lanza cuando /, // o % tienen un divisor igual a cero.
Unary operator (operador unario)
Un operador como -x o +x que recibe un solo operando.
Concatenation (concatenación)
Unir dos cadenas con +, lo que produce una cadena nueva.
Replication (replicación)
Repetir una cadena (o lista) con * y un número entero de veces.
Assignment operator (=) (operador de asignación)
Vincula el nombre de la izquierda al valor de la expresión de la derecha.
Compound assignment (asignación compuesta)
Un operador como += o //= que aplica una operación y vuelve a vincular la variable al resultado.
Chained assignment (asignación encadenada)
Vincular varios nombres a un mismo valor en una sola instrucción, como en a = b = 0.
Immutable (inmutable)
Que no puede modificarse en su lugar; las cadenas son inmutables, así que las operaciones con cadenas construyen cadenas nuevas.
Priority (precedence) (prioridad, precedencia)
La regla que decide qué operadores se aplican primero en una expresión.
Binding (associativity) (asociatividad)
El orden en que se aplican los operadores de igual prioridad, normalmente de izquierda a derecha.
Right-to-left binding (asociatividad de derecha a izquierda)
El comportamiento de **, de modo que a ** b ** c significa a ** (b ** c).
Parentheses (paréntesis)
Signos que obligan a evaluar primero una subexpresión, por encima de la prioridad.
Bitwise AND (&) (AND a nivel de bits)
Produce 1 en cada posición de bit donde ambos operandos tienen 1.
Bitwise OR (|) (OR a nivel de bits)
Produce 1 en cada posición de bit donde al menos un operando tiene 1.
Bitwise XOR (^) (XOR a nivel de bits)
Produce 1 en cada posición de bit donde los operandos son diferentes.
Bitwise NOT (~) (NOT a nivel de bits)
Invierte todos los bits; para los ints de Python, ~x es igual a -x - 1.
Shift (<< >>) (desplazamiento)
Mueve los bits a la izquierda o a la derecha, multiplicando o haciendo división entera por potencias de dos.
Bit mask (máscara de bits)
Un número que se usa con &, | o ^ para comprobar, activar, apagar o alternar bits elegidos.
Relational operator (operador relacional)
Un operador como ==, != o <= que compara dos valores y devuelve True o False.
Chained comparison (comparación encadenada)
Una expresión como 0 <= x < 5, equivalente a dos comparaciones unidas por and.
Logical operator (operador lógico)
and, or o not, que se usan para combinar o invertir condiciones booleanas.
Floating-point error (error de punto flotante)
La pequeña imprecisión causada por almacenar fracciones decimales en binario, como en 0.1 + 0.2.
Banker's rounding (redondeo bancario)
La regla de round() de enviar las mitades exactas al entero par más cercano.
Tolerance comparison (comparación con tolerancia)
Comprobar floats con abs(a - b) < valor_pequeño en lugar de ==.
Type casting (conversión de tipos)
Convertir explícitamente un valor a otro tipo con una función como int() o str().
Implicit conversion (conversión implícita)
La promoción automática de un int a float cuando ambos se mezclan en una operación aritmética.
Truncation (truncamiento)
Descartar la parte fraccionaria hacia cero, como hace int() con los floats.
Truthiness (veracidad)
La regla que usa bool(): el cero, lo vacío y None son False; todo lo demás es True.
ValueError
Se lanza cuando una función de conversión recibe un tipo aceptable pero un valor inutilizable, como int("3.7").
TypeError
Se lanza cuando una operación o función recibe un valor de un tipo no admitido, como int(None).
print()
Función integrada que escribe sus argumentos, convertidos en texto, en la consola, separados por sep y seguidos de end.
sep=
Argumento de palabra clave de print() que indica la cadena insertada entre los argumentos; por defecto es un solo espacio.
end=
Argumento de palabra clave de print() que indica la cadena impresa después del último argumento; por defecto es un salto de línea.
input()
Función integrada que lee una línea del usuario y siempre la devuelve como cadena.
Prompt (mensaje de aviso)
La cadena opcional que se pasa a input() y se muestra antes de que el usuario escriba.
Escape sequence (secuencia de escape)
Una combinación con barra invertida, como \n o \t, que representa un carácter especial dentro de una cadena.

Dominio 2: Control flow: conditional blocks and loops (29%)

Consejos para el examen

  • Cuenta cuántas ramas pueden ejecutarse. Una cadena if-elif-else ejecuta exactamente un bloque (o ninguno si no hay else); una pila de if separados puede ejecutar varios. Esa sola distinción responde muchas preguntas de salida del PCEP.
  • Cuando el examen imprime el resultado de and u or, no respondas True o False por reflejo. and devuelve el primer operando falsy (o el último); or devuelve el primer operando truthy (o el último).
  • Empareja else y elif con su if usando la columna de indentación, no el orden en que aparecen. Las mismas palabras con otra indentación producen un programa distinto.
  • pass no salta ni sale de nada; el código que viene después en el mismo bloque se sigue ejecutando. Si una opción de respuesta trata a pass como continue, es incorrecta.
  • Cuenta con cuidado: la condición de un bucle while se comprueba una vez más de las que se ejecuta el cuerpo. Vigila también las condiciones con != que un paso puede saltarse.
  • El valor de parada nunca se incluye, y un rango que no puede avanzar desde el inicio hacia la parada en la dirección del paso está vacío, no es un error.
  • Cambiar la variable del bucle nunca cambia la secuencia. Si una pregunta hace for x in lst: x += 1 y luego imprime lst, la lista no ha cambiado.
  • break nunca salta fuera de dos bucles. Cuando una pregunta con bucles anidados usa break, solo se detiene el bucle interior; sigue contando las iteraciones del bucle exterior.
  • Lee el else que va después de un bucle como si no hubo break. Un bucle vacío igual ejecuta su else, y continue no lo impide.
  • Si el rango interior usa la variable exterior, nunca multipliques; anota la cuenta interior para cada valor exterior y súmalas.
  • Después de for i in range(n), i vale n - 1; después de un bucle while de conteo, el contador suele valer n. Después de un bucle for vacío, la variable no cambia o no está definida.

Términos clave

if statement (instrucción if)
Ejecuta su bloque indentado solo cuando su condición es verdadera.
elif
Una condición adicional que se prueba solo si todas las condiciones anteriores de la misma instrucción fueron falsas.
else
La rama que se ejecuta cuando ninguna condición if o elif anterior fue verdadera; no lleva condición.
Condition (condición)
Cualquier expresión cuyo valor de verdad decide si un bloque se ejecuta.
Overlapping conditions (condiciones superpuestas)
Condiciones que pueden ser verdaderas al mismo tiempo, lo que hace que el orden de las ramas elif sea importante.
Unreachable branch (rama inalcanzable)
Una rama que nunca puede ejecutarse porque una condición anterior siempre atrapa sus casos.
Chained comparison (comparación encadenada)
Una expresión como 80 <= score < 90 que prueba un rango completo en una sola condición.
Truthy (verdadero en contexto booleano)
Cualquier valor que cuenta como verdadero en una condición, como los números distintos de cero y las colecciones no vacías.
Falsy (falso en contexto booleano)
Un valor que cuenta como falso: False, None, el cero y las cadenas o colecciones vacías.
Short-circuit evaluation (evaluación en cortocircuito)
and y or dejan de evaluar en cuanto se conoce el resultado.
Logical operator (operador lógico)
and, or o not, usados para combinar o invertir condiciones.
De Morgan's laws (leyes de De Morgan)
Reglas para negar condiciones combinadas: not (a and b) equivale a not a or not b, y viceversa.
Operator precedence (prioridad de operadores)
El orden en que Python aplica los operadores: primero las comparaciones, luego not, luego and y luego or.
Nested conditional (condicional anidada)
Una instrucción if dentro del bloque de otra rama condicional.
Indentation level (nivel de indentación)
La columna en la que empieza una línea; define a qué bloque pertenece la línea.
Dangling else (else colgante)
La pregunta de a qué if pertenece un else; en Python, al que está a la misma indentación.
Flattening (aplanamiento)
Reemplazar if anidados por and o por una cadena elif para reducir la profundidad de indentación.
Logic error (error de lógica)
Un fallo que deja que el programa se ejecute pero produce un comportamiento incorrecto, como un else mal colocado.
IndentationError
Una subclase de SyntaxError que se lanza antes de ejecutar el programa cuando las líneas de un bloque no se alinean correctamente.
pass
Una instrucción (palabra clave) que no hace nada, usada donde la sintaxis requiere una instrucción.
Stub (esqueleto)
Una función o bloque de relleno, a menudo con cuerpo pass, que se completará más adelante.
Empty block error (error de bloque vacío)
IndentationError: expected an indented block, que se lanza cuando un encabezado con dos puntos no tiene cuerpo.
Compound statement (instrucción compuesta)
Una instrucción como if, for, while o def cuyo encabezado termina en dos puntos y tiene un bloque indentado propio.
continue
A diferencia de pass, salta el resto de la iteración actual del bucle.
break
A diferencia de pass, sale del bucle por completo.
while loop (bucle while)
Un bucle que repite su cuerpo mientras su condición sea verdadera, comprobándola antes de cada iteración.
Iteration (iteración)
Una ejecución del cuerpo de un bucle.
Loop condition (condición del bucle)
La expresión que se comprueba antes de cada iteración; el bucle termina cuando es falsy.
Infinite loop (bucle infinito)
Un bucle cuya condición nunca se vuelve falsa, así que se ejecuta hasta que se interrumpe o se sale de él con break.
KeyboardInterrupt
La excepción que se lanza cuando el usuario presiona Ctrl+C, usada para detener un programa descontrolado.
Sentinel value (valor centinela)
Una entrada especial, como quit, que le dice a un bucle que se detenga.
range()
Función integrada que produce enteros desde start hasta stop sin incluirlo, avanzando de step en step.
Start (inicio)
El primer valor de un rango; 0 si se omite.
Stop (parada)
El valor límite, que nunca se incluye en el rango.
Step (paso)
La cantidad que se suma cada vez; los pasos negativos cuentan hacia abajo y 0 no está permitido.
Empty range (rango vacío)
Un rango que no produce valores, como range(5, 2), así que un bucle sobre él se ejecuta cero veces.
Loop variable (variable del bucle)
El nombre que toma cada valor sucesivo en un bucle for.
Off-by-one error (error de uno más o uno menos)
Un fallo en el que un bucle se ejecuta una vez de más o de menos, causado a menudo por olvidar que stop se excluye.
Iterable
Un objeto cuyos elementos se pueden tomar uno a la vez, como una cadena, lista, tupla, dict o range.
enumerate()
Función integrada que produce pares (índice, elemento) mientras se itera.
Accumulator (acumulador)
Una variable que se prepara antes de un bucle y se actualiza en cada iteración para construir un total o un resultado.
Immutable string (cadena inmutable)
Una cadena no se puede cambiar en el lugar; los bucles construyen cadenas nuevas en su lugar.
range(len(seq))
Un patrón que recorre los índices válidos de una secuencia.
Membership test (prueba de pertenencia)
El operador in usado en una expresión, que devuelve True o False.
Innermost loop (bucle más interno)
El bucle que contiene de forma más directa a una instrucción; break y continue actúan solo sobre él.
Flag variable (variable bandera)
Un booleano que se asigna dentro de un bucle para señalar un evento, como found = True, y que se comprueba después para detener un bucle exterior.
Early exit (salida anticipada)
Salir de un bucle antes de su final natural, normalmente con break o return.
Loop else clause (cláusula else de un bucle)
Un bloque después de un bucle for o while que se ejecuta solo si el bucle terminó sin break.
Normal termination (terminación normal)
Un bucle que termina porque su condición se volvió falsa o porque se acabaron sus elementos.
Search loop (bucle de búsqueda)
Un bucle que busca un elemento y hace break cuando lo encuentra, a menudo acompañado de else para el caso de no encontrado.
Nested loop (bucle anidado)
Un bucle colocado dentro del cuerpo de otro bucle; el bucle interior se completa por entero en cada iteración exterior.
Outer loop (bucle exterior)
El bucle que contiene al otro, y que controla cuántas veces se inicia el bucle interior.
Inner loop (bucle interior)
El bucle contenido, que vuelve a empezar desde el principio en cada iteración exterior.
Iteration count (número de iteraciones)
El total de veces que se ejecuta el cuerpo de un bucle, que se obtiene multiplicando o sumando por cada pasada exterior.
Dependent range (rango dependiente)
Un rango interior cuyos límites usan la variable del bucle exterior, así que las cuentas cambian en cada pasada exterior.
Loop variable scope (ámbito de la variable del bucle)
En Python, la variable de un bucle for sigue definida después del bucle, con su último valor.
Last assigned value (último valor asignado)
Para range(n), la variable del bucle termina en n - 1, no en n.
Counter variable (variable contador)
Una variable que el propio bucle while actualiza; suele terminar un paso más allá de la última comprobación que se cumplió.
NameError
Se lanza si usas una variable de bucle que nunca se asignó porque el bucle se ejecutó cero veces.
Tracing (rastreo)
Registrar el valor de cada variable paso a paso para predecir la salida de un programa.

Dominio 3: Data collections: tuples, dictionaries, lists and strings (25%)

Consejos para el examen

  • Los índices fuera de rango lanzan IndexError, pero las rebanadas fuera de rango devuelven sin quejarse lo que existe, posiblemente una lista vacía. Una rebanada de un elemento sigue siendo una lista, así que x[0] y x[0:1] se imprimen de forma distinta.
  • Los métodos que modifican una lista en el lugar (append, insert, remove, sort, reverse) devuelven None. Si una respuesta imprime el resultado de x.sort(), imprime None. remove() trabaja por valor; del y pop(), por posición.
  • Un if al final filtra (menos elementos, no admite else); un if-else al principio transforma (misma cantidad de elementos, else obligatorio). Recuerda también que in no busca dentro de listas anidadas.
  • b = a nunca copia una lista. Si una pregunta muta b después de esa línea, a también cambia. Las rebanadas, list() y copy() crean listas exteriores nuevas, pero las listas anidadas dentro siguen compartidas.
  • grid[1][2] es la fila 1, columna 2, ambas contadas desde 0. Y [[0] * 3] * 3 crea tres referencias a una misma fila, así que una sola asignación aparece en todas las filas.
  • La coma, no los paréntesis, es lo que crea una tupla. (7) es un int, (7,) es una tupla, y 7, también es una tupla. Cualquier intento de asignar a t[i] lanza TypeError.
  • d[key] con una clave inexistente lanza KeyError; d.get(key) devuelve None. Asignar d[key] = value nunca falla: agrega si es nueva y reemplaza si ya existe.
  • in sobre un diccionario comprueba claves, no valores. Recorrer un diccionario da las claves; usa items() para obtener ambas partes a la vez.
  • Las mayúsculas se ordenan antes que las minúsculas, y las cadenas de dígitos se comparan como texto, así que "100" < "20" es True. Cualquier intento de asignar a s[i] es un TypeError.
  • Cada secuencia de escape cuenta como un carácter al medir la longitud. Una cadena que termina en una sola barra invertida es un error de sintaxis, porque la barra invertida escapa la comilla de cierre.
  • Los métodos de cadena devuelven cadenas nuevas; la original nunca cambia. find() devuelve -1 en lugar de fallar, y join() se llama sobre el separador, no sobre la lista.

Términos clave

List (lista)
Una secuencia ordenada y mutable de valores escrita entre corchetes, como [1, 2, 3].
Index (índice)
Una posición entera que se usa entre corchetes para seleccionar un elemento, empezando en 0 por la izquierda.
Negative index (índice negativo)
Una posición contada desde el final de una secuencia, donde -1 es el último elemento.
Slice (rebanada)
La expresión lst[start:stop:step], que devuelve una lista nueva desde start hasta stop sin incluirlo.
Step (paso)
El tercer valor de la rebanada, que indica el salto entre elementos; un paso negativo recorre de derecha a izquierda.
IndexError
La excepción que se lanza cuando un índice cae fuera del intervalo válido de una secuencia.
Mutable
Que puede cambiarse en el lugar; las listas son mutables, así que puedes asignar mediante un índice o una rebanada.
Method (método)
Una función asociada a un objeto que se llama con notación de punto, como lst.append(x).
In-place operation (operación en el lugar)
Una operación que modifica el objeto existente en lugar de crear uno nuevo, y que normalmente devuelve None.
append()
Un método de listas que agrega un único elemento, que puede ser a su vez una lista, al final de la lista.
insert()
Un método de listas que coloca un elemento antes de la posición indicada y desplaza a la derecha los elementos posteriores.
remove()
Un método de listas que elimina el primer elemento igual a un valor dado y lanza ValueError si no existe ninguno.
sorted()
Una función integrada que devuelve una lista nueva ordenada a partir de cualquier iterable y deja el original sin cambios.
del
Una instrucción que elimina elementos de una lista por índice o por rebanada, o que borra por completo el nombre de una variable.
Iteration (iteración)
Recorrer los elementos de una colección uno a uno, normalmente con un bucle for.
enumerate()
Una función integrada que produce pares (índice, valor) para que un bucle pueda usar tanto la posición como el elemento.
Membership operator (operador de pertenencia)
Los operadores in y not in, que devuelven True o False según si un valor está presente.
List comprehension (lista por comprensión)
Una expresión de la forma [expr for item in iterable] que construye una lista nueva en una línea.
Filter condition (condición de filtro)
Un if al final de una comprensión que conserva solo los elementos para los que la condición es verdadera.
Conditional expression (expresión condicional)
La forma a if condition else b, que se evalúa a uno de dos valores y puede transformar elementos en una comprensión.
Reference (referencia)
El vínculo entre el nombre de una variable y un objeto en memoria; los nombres guardan referencias, no los objetos en sí.
Alias
Un segundo nombre vinculado al mismo objeto, de modo que los cambios hechos a través de un nombre se ven a través del otro.
Shallow copy (copia superficial)
Una lista exterior nueva que contiene referencias a los mismos objetos internos, hecha con a[:], list(a) o a.copy().
Deep copy (copia profunda)
Una copia que también duplica cada objeto anidado, hecha con copy.deepcopy().
Identity operator (operador de identidad)
El operador is, que devuelve True solo cuando dos nombres se refieren exactamente al mismo objeto.
Mutation (mutación)
Cambiar un objeto en el lugar, por ejemplo con append(), con asignación a un elemento o con +=, en lugar de crear un objeto nuevo.
Nested list (lista anidada)
Una lista que contiene otras listas como elementos.
Matrix (matriz)
Una cuadrícula rectangular de valores, representada en Python como una lista de filas de igual longitud.
Row index (índice de fila)
El primer índice en grid[r][c], que selecciona qué lista interna usar.
Column index (índice de columna)
El segundo índice en grid[r][c], que selecciona el elemento dentro de la fila elegida.
Jagged list (lista irregular)
Una lista anidada cuyas listas internas tienen longitudes distintas.
Nested loop (bucle anidado)
Un bucle dentro de otro bucle, usado para visitar cada elemento de una estructura bidimensional.
Tuple (tupla)
Una secuencia ordenada e inmutable, normalmente escrita con paréntesis y comas, como (3, 4).
Immutable (inmutable)
Que no se puede cambiar después de creado; cualquier "cambio" produce un objeto nuevo.
One-item tuple (tupla de un elemento)
Una tupla con un único elemento, que requiere una coma final, como en (5,).
Tuple packing (empaquetado de tuplas)
Crear una tupla escribiendo valores separados por comas, como en t = 1, 2, 3.
Unpacking (desempaquetado)
Asignar los elementos de una secuencia a varios nombres a la vez, como en x, y = (3, 4).
Hashable
Que puede servir como clave de diccionario o como miembro de un conjunto; los valores inmutables, como las tuplas de elementos inmutables, cumplen esta condición.
Dictionary (diccionario)
Una colección mutable de pares clave-valor, escrita como {key: value}, que se consulta por clave y no por posición.
Key (clave)
El identificador único y hashable que se usa para guardar y recuperar un valor en un diccionario.
Value (valor)
El dato asociado a una clave; puede ser de cualquier tipo y no tiene que ser único.
KeyError
La excepción que se lanza al indexar, eliminar o hacer pop de una clave que no está en el diccionario.
get()
Un método de diccionario que devuelve el valor de una clave, o None o un valor por defecto indicado si la clave no existe.
pop()
Un método de diccionario que elimina una clave y devuelve su valor, y lanza KeyError si no existe y no se indica un valor por defecto.
update()
Un método de diccionario que agrega o sobrescribe pares tomados de otro diccionario.
keys()
Un método de diccionario que devuelve una vista de todas las claves en orden de inserción.
values()
Un método de diccionario que devuelve una vista de todos los valores, que puede contener duplicados.
items()
Un método de diccionario que devuelve una vista de tuplas (clave, valor), ideal para bucles que necesitan ambas cosas.
View object (objeto vista)
Una ventana viva e iterable a las claves, valores o pares de un diccionario, que refleja los cambios posteriores y no se puede indexar.
Membership test (prueba de pertenencia)
Usar in o not in sobre un diccionario para comprobar si está presente una clave, no un valor.
RuntimeError
La excepción que se lanza cuando un diccionario cambia de tamaño mientras se está recorriendo.
String (cadena)
Una secuencia inmutable de caracteres Unicode, escrita entre comillas, como "Python".
Immutability (inmutabilidad)
La propiedad por la que los caracteres de una cadena no se pueden cambiar en el lugar; los cambios crean una cadena nueva.
Reverse slice (rebanada inversa)
La rebanada s[::-1], que devuelve una cadena nueva con los caracteres en orden inverso.
Lexicographic order (orden lexicográfico)
Comparación al estilo de un diccionario, carácter por carácter, en la que la primera diferencia decide el resultado.
Code point (punto de código)
El número que Unicode asigna a un carácter, que devuelve ord() y que chr() vuelve a convertir en carácter.
Concatenation (concatenación)
Unir cadenas con + para crear una cadena nueva.
Escape character (carácter de escape)
La barra invertida \, que da un significado especial al carácter siguiente dentro de un literal de cadena.
Escape sequence (secuencia de escape)
Una barra invertida y un carácter, como \n o \', que juntos representan un solo carácter.
Newline (salto de línea)
El carácter de salto de línea, escrito \n, que lleva la salida a la línea siguiente.
Raw string (cadena cruda)
Un literal con el prefijo r, en el que las barras invertidas se conservan como caracteres normales.
Triple-quoted string (cadena con comillas triples)
Un literal delimitado por ''' o """ que puede ocupar varias líneas y contener ambos tipos de comillas.
Docstring
Un literal de cadena colocado al principio del cuerpo de una función, clase o módulo para documentarlo.
split()
Devuelve una lista de subcadenas, dividiendo por espacios en blanco por defecto o por un separador indicado.
join()
Se llama sobre una cadena separadora y devuelve una sola cadena formada al unir un iterable de cadenas.
strip()
Devuelve una copia sin espacios en blanco, o sin los caracteres indicados, en ambos extremos.
find()
Devuelve el índice de la primera aparición de una subcadena, o -1 si no está.
count()
Devuelve el número de apariciones sin solapamiento de una subcadena.
replace()
Devuelve una copia en la que las apariciones de una subcadena se reemplazan por otra, con un límite opcional de reemplazos.

Dominio 4: Functions and exceptions (28%)

Consejos para el examen

  • Las preguntas del examen sobre descomposición se centran en el porqué: reutilización, legibilidad, pruebas más fáciles y trabajo en equipo. Una función que devuelve un valor es más reutilizable que una que solo lo imprime.
  • Un def debe ejecutarse antes de que se ejecute la llamada, pero el cuerpo de una función puede referirse a otra función definida más abajo, porque los nombres dentro de un cuerpo se buscan solo en el momento de la llamada.
  • Si una función no tiene return (o tiene un return solo), su llamada se evalúa a None; print(f()) mostrará None después de lo que imprima f. Un return con valores separados por comas da una tupla.
  • Al rastrear una recursión, escribe cada llamada en su propia línea con su argumento, baja hasta el caso base y luego multiplica o suma al volver hacia arriba. Un caso base que los argumentos pueden saltarse es tan malo como no tener ninguno.
  • Siempre posicionales antes que por palabra clave. Un argumento por palabra clave antes de uno posicional es un SyntaxError; darle dos valores a un parámetro o usar un nombre inexistente es un TypeError.
  • Los valores por defecto van a la derecha. def f(a=1, b) ni siquiera llega a definirse: es un SyntaxError al definir la función, no un error al llamarla.
  • Cualquier asignación a un nombre en cualquier parte de una función lo hace local en toda la función, así que leerlo antes en esa misma función lanza UnboundLocalError en lugar de leer la global.
  • Aprende qué clases están bajo cuáles: IndexError y KeyError bajo LookupError, ZeroDivisionError bajo ArithmeticError, y SystemExit y KeyboardInterrupt directamente bajo BaseException, fuera de Exception.
  • TypeError tiene que ver con el tipo de valor; ValueError, con el valor concreto. list.index() y list.remove() con un elemento inexistente lanzan ValueError, no IndexError.
  • Solo se ejecuta el primer except que coincide. Un except solo debe ir al final y captura incluso KeyboardInterrupt; except Exception no captura SystemExit ni KeyboardInterrupt.
  • Recorre las cláusulas except estrictamente de arriba abajo y detente en la primera clase que sea la misma o un ancestro. Una clase general encima de una específica convierte la rama específica en código muerto, y Python no te avisa.
  • Cuando una excepción escapa de una función, se omiten todas las líneas restantes de esa función, incluido su return. La excepción la captura el try envolvente más cercano con un except que coincida, en cualquier punto de la cadena de llamadas hacia arriba.

Términos clave

Decomposition (descomposición)
Dividir un problema en subproblemas más pequeños, cada uno resuelto por su propia función.
Function (función)
Un bloque de código con nombre y reutilizable que realiza una tarea y puede recibir argumentos y devolver un valor.
Abstraction (abstracción)
Usar algo a través de su nombre y su interfaz sin necesidad de saber cómo funciona por dentro.
Reuse (reutilización)
Escribir el código una vez y llamarlo desde muchos lugares, de modo que las correcciones y mejoras se aplican en todas partes.
Top-down design (diseño de arriba hacia abajo)
Escribir primero los pasos principales como llamadas a funciones y luego implementar cada función por turno.
Module (módulo)
Un archivo de Python con definiciones que otro código puede incorporar con import.
def
La palabra clave que inicia la definición de una función, seguida del nombre, los parámetros entre paréntesis y dos puntos.
Function body (cuerpo de la función)
El bloque de instrucciones con sangría que se ejecuta cada vez que se llama a la función.
Invocation (invocación)
Llamar a una función escribiendo su nombre seguido de paréntesis y los argumentos que lleve.
Function object (objeto función)
El objeto que crea una instrucción def, vinculado al nombre de la función y que se puede llamar con paréntesis.
NameError
La excepción que se lanza cuando el código usa un nombre, como una función, que todavía no se ha definido.
Not callable (no invocable)
El TypeError que se lanza cuando se aplican paréntesis a un objeto que no es una función, como un entero.
return
Una instrucción que termina una función y envía un valor, o None si no se indica ninguno, a quien la llamó.
None
El único valor del tipo NoneType, que significa "sin valor"; lo devuelven las funciones que no devuelven ninguna otra cosa.
Implicit return (retorno implícito)
El return None automático que ocurre cuando una función llega al final de su cuerpo.
Tuple return (retorno de tupla)
Devolver varios valores separados por comas, que Python empaqueta en una sola tupla.
yield
Una instrucción que convierte una función en generadora: entrega un valor y se pausa hasta que se pide el siguiente.
Generator (generador)
Un objeto que se obtiene al llamar a una función generadora y que produce valores uno a uno, a medida que se piden.
Recursion (recursión)
Una técnica en la que una función resuelve un problema llamándose a sí misma con una versión más pequeña de él.
Base case (caso base)
La condición en la que una función recursiva devuelve un resultado directamente, sin llamarse a sí misma.
Recursive case (caso recursivo)
La rama que vuelve a llamar a la función con un argumento más cercano al caso base.
Call stack (pila de llamadas)
La pila de llamadas a funciones activas, cada una con sus propias variables locales, que esperan resultados.
RecursionError
La excepción, subclase de RuntimeError, que se lanza cuando se supera la profundidad máxima de recursión.
Recursion limit (límite de recursión)
La profundidad máxima de llamadas que Python permite, consultable con sys.getrecursionlimit().
Parameter (parámetro)
Un nombre que aparece en la definición de una función y que recibe un valor cuando se llama a la función.
Argument (argumento)
El valor o la expresión real que se proporciona en una llamada a función.
Positional argument (argumento posicional)
Un argumento que se asocia a un parámetro según su posición en la llamada.
Keyword argument (argumento por palabra clave)
Un argumento escrito como name=value que se asocia al parámetro con ese nombre.
Mixed passing (paso mixto)
Una llamada que usa argumentos posicionales seguidos de argumentos por palabra clave.
Binding (vinculación)
Asociar el nombre de un parámetro con el objeto del argumento mientras dura una llamada.
Default value (valor por defecto)
Un valor que se le da a un parámetro en la definición y que se usa cuando quien llama no proporciona ningún argumento para él.
Required parameter (parámetro obligatorio)
Un parámetro sin valor por defecto, que toda llamada debe proporcionar.
Optional parameter (parámetro opcional)
Un parámetro con valor por defecto, que quien llama puede omitir.
Definition time (momento de la definición)
El momento en que se ejecuta la instrucción def, cuando los valores por defecto se evalúan una sola vez y se crea el objeto función.
Mutable default (valor por defecto mutable)
Un valor por defecto como una lista o un diccionario que comparten todas las llamadas que lo usan, de modo que los cambios persisten entre llamadas.
None sentinel (centinela None)
Usar None como valor por defecto y crear un objeto nuevo dentro de la función cuando el argumento es None.
Scope (ámbito)
La región de un programa en la que un nombre es visible y se puede usar.
Local variable (variable local)
Un nombre asignado dentro de una función, incluidos sus parámetros, que solo existe durante esa llamada.
Global variable (variable global)
Un nombre asignado en el nivel superior de un módulo, visible para todas las funciones de ese archivo.
Shadowing (ocultamiento)
Un nombre local que oculta, dentro de una función, a un nombre global o integrado escrito igual.
global keyword (palabra clave global)
Una declaración que hace que las asignaciones a un nombre dentro de una función afecten a la variable global.
UnboundLocalError
Una subclase de NameError que se lanza cuando una variable local se lee antes de haberse asignado en la función.
LEGB rule (regla LEGB)
El orden de búsqueda de los nombres: local, envolvente, global y, por último, integrado.
Exception (excepción)
Un objeto que señala un error en tiempo de ejecución; también es el nombre de la clase base de todos los errores comunes.
BaseException
La clase raíz de la que hereda toda excepción de Python.
SystemExit
La excepción que lanza sys.exit() para terminar un programa; hereda directamente de BaseException.
KeyboardInterrupt
La excepción que se lanza cuando el usuario pulsa Ctrl+C; hereda directamente de BaseException.
ArithmeticError
La clase base de los errores numéricos, incluidos ZeroDivisionError y OverflowError.
LookupError
La clase base de los errores por índice o clave no válidos, incluidos IndexError y KeyError.
issubclass()
Una función integrada que devuelve True si una clase hereda de otra o si es la misma clase.
ZeroDivisionError
Se lanza cuando el divisor de /, // o % es cero; es una subclase de ArithmeticError.
IndexError
Se lanza cuando un índice de secuencia está fuera del rango válido; es una subclase de LookupError.
KeyError
Se lanza cuando no se encuentra una clave de diccionario; es una subclase de LookupError.
TypeError
Se lanza cuando una operación se aplica a un valor de un tipo inadecuado.
ValueError
Se lanza cuando un valor tiene el tipo correcto pero un contenido inadecuado, como int("abc").
Traceback
El informe que Python imprime para una excepción no manejada, que termina con el tipo de excepción y el mensaje.
try block (bloque try)
El bloque de código que Python vigila en busca de excepciones.
except clause (cláusula except)
Un manejador que se ejecuta cuando el bloque try lanza una excepción de la clase nombrada o de una subclase.
Bare except (except solo)
Un except: sin clase, que captura todas las excepciones, incluidas SystemExit y KeyboardInterrupt, y debe ir al final.
except Exception
Un manejador que captura todos los errores comunes y deja pasar SystemExit y KeyboardInterrupt.
else clause (cláusula else)
Un bloque opcional después de las cláusulas except que se ejecuta solo si el bloque try no lanzó nada.
finally clause (cláusula finally)
Un bloque opcional que se ejecuta haya ocurrido una excepción o no, y que se usa para la limpieza.
First-match rule (regla de la primera coincidencia)
Python ejecuta solo la primera cláusula except, de arriba abajo, cuya clase coincide con la excepción lanzada.
Specific exception (excepción específica)
Una clase baja en la jerarquía, como KeyError, que describe un tipo de error preciso.
General exception (excepción general)
Una clase alta en la jerarquía, como LookupError o Exception, que cubre muchos tipos de error.
Unreachable branch (rama inalcanzable)
Una cláusula except que nunca puede ejecutarse porque una cláusula anterior ya captura todo lo que ella capturaría.
Ancestor class (clase ancestro)
Una clase situada más arriba en la jerarquía, de la que hereda una clase de excepción dada.
Safety net (red de seguridad)
Un manejador general final, normalmente except Exception, que captura los errores que no manejaron las cláusulas anteriores.
Propagation (propagación)
El movimiento de una excepción no manejada desde una función hacia quien la llamó, y así sucesivamente hacia arriba por la cadena de llamadas.
Call chain (cadena de llamadas)
La secuencia de llamadas a funciones activas en un momento dado, desde el código de nivel superior hasta la función actual.
raise
Una instrucción que lanza una excepción a propósito, como raise ValueError("bad input").
Re-raise (volver a lanzar)
Usar un raise solo dentro de un bloque except para que la excepción actual siga propagándose.
Handler placement (ubicación del manejador)
La decisión de diseño sobre qué nivel captura una excepción, idealmente el que sabe cómo responder.
