Usar nmtui como alternativa en modo texto a nmcli

nmtui, abreviatura de NetworkManager text user interface (interfaz de usuario de texto de NetworkManager), es un programa con menús para las mismas tareas cotidianas que haces con nmcli. Funciona en cualquier terminal, incluida la consola remota del examen, y te mueves por él con las flechas, Tab, Enter y la barra espaciadora. Como ambas herramientas son clientes de NetworkManager, leen y escriben los mismos perfiles de conexión, guardados como keyfiles en /etc/NetworkManager/system-connections/. Con la presión del tiempo del examen, muchas personas encuentran nmtui más rápido y con menos riesgo de error para cambios puntuales, porque cada campo tiene su etiqueta y nunca necesitas recordar nombres exactos de propiedades como ipv4.addresses o ipv4.method. El comando viene del paquete NetworkManager-tui, que puede no estar instalado de forma predeterminada, así que prepárate para ejecutar dnf install -y NetworkManager-tui.
