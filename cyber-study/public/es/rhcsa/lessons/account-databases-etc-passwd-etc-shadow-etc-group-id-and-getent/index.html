Red Hat Certified System Administrator EX200 (RHEL 10)

Bases de datos de cuentas: /etc/passwd, /etc/shadow, /etc/group; id y getent

Las cuentas locales en RHEL se guardan en archivos de texto plano con una línea por entrada y campos separados por dos puntos. Leer estos archivos con soltura te permite verificar cualquier tarea de usuarios o grupos en segundos y detectar errores como un shell incorrecto, un miembro de grupo que falta o una contraseña que nunca se estableció. Puedes inspeccionarlos con total libertad, pero cámbialos con las herramientas adecuadas, como useradd, usermod, chage y groupmod. Si alguna vez tienes que editarlos a mano, usa vipw para el archivo passwd y vigr para el archivo group, que bloquean los archivos para que ninguna otra herramienta escriba en ellos al mismo tiempo y que también ofrecen editar el archivo shadow correspondiente.
