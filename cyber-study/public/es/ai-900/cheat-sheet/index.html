Dominio 1: Describe AI workloads and considerations (19%)

Consejos para el examen

  • Si un escenario dice que el resultado es difícil de expresar como reglas y que hay muchos datos históricos de ejemplo, la respuesta implica aprendizaje automático. Recuerda que las salidas de los modelos son probabilísticas, así que las respuestas que afirman que la IA siempre acierta son incorrectas. Recuerda también la división: servicios de Azure AI para capacidades preentrenadas y Azure Machine Learning para entrenar tus propios modelos.
  • Busca el verbo en el escenario: predecir o estimar apunta a predicción con ML, marcar lo inusual apunta a detección de anomalías, ver o leer una imagen apunta a visión artificial, entender texto apunta a NLP, extraer campos de formularios apunta a procesamiento de documentos, buscar en muchos archivos apunta a minería de conocimiento, y crear o redactar apunta a IA generativa.
  • Contar y ubicar significa detección de objetos; una etiqueta para toda la imagen significa clasificación; leer texto significa OCR. Si una pregunta menciona identificar quién es una persona, espera que Limited Access forme parte de la respuesta correcta, y recuerda que la inferencia de emoción, género y edad está retirada.
  • Distingue la dirección de las tareas de habla: speech to text produce transcripciones y subtítulos; text to speech produce audio. Las tareas de análisis (sentimiento, frases clave, entidades) nunca generan texto nuevo. Para un bot tradicional, recuerda la pareja: intención y entidades.
  • El OCR por sí solo te da texto; el procesamiento de documentos te da campos y tablas; la minería de conocimiento te da un índice consultable sobre muchos documentos. Elige el que coincida con la salida que pide el escenario: Document Intelligence para campos y Azure AI Search para colecciones consultables.
  • Copiloto: ayuda a un usuario dentro de una app. Agente: además puede usar herramientas y realizar acciones. Ambos son IA generativa. Busca las palabras 'crear', 'redactar' o 'escribir' como señal de una carga de trabajo de IA generativa, y espera preguntas de riesgo sobre alucinaciones y contenido dañino.
  • Resultados desiguales entre grupos apuntan a equidad. Probar casos extremos, manejar fallas de forma segura, sistemas de seguridad de contenido o supervisar la deriva apuntan a confiabilidad y seguridad. Recuerda los seis principios: equidad, confiabilidad y seguridad, privacidad y seguridad, inclusión, transparencia y rendición de cuentas.
  • La protección de datos, el consentimiento, el cifrado, la censura de PII y el control de acceso corresponden a privacidad y seguridad. La accesibilidad, los idiomas y el diseño para personas con discapacidad corresponden a inclusión. Si un grupo no puede usar el sistema, piensa en inclusión; si un grupo recibe peores decisiones, piensa en equidad.
  • Explicar, divulgar o documentar apunta a transparencia. Ser responsable, gobernar, revisar, aprobar o responder por algo apunta a rendición de cuentas. En las preguntas, ambas suelen aparecer junto con Limited Access, las notas de transparencia y las funciones de interpretabilidad del Responsible AI dashboard.
  • Si una pregunta plantea por qué la identificación facial requiere una solicitud, la respuesta es Limited Access para un uso responsable, no el precio ni el estado de versión preliminar. Azure AI Face ya no ofrece inferencia de emoción, género ni edad. Asocia la evaluación de impacto con 'antes de construir' y human in the loop con 'aprobar antes de que surta efecto'.

Términos clave

Artificial intelligence (AI, inteligencia artificial)
Software que imita capacidades humanas como ver, entender el lenguaje, predecir y crear contenido.
Machine learning (ML, aprendizaje automático)
La técnica de construir modelos entrenando algoritmos con datos de ejemplo en lugar de escribir reglas explícitas.
Model (modelo)
Una función aprendida a partir de datos que recibe una entrada nueva y devuelve una predicción, etiqueta, puntuación o contenido generado.
Training (entrenamiento)
El proceso de ajustar los valores internos de un modelo usando datos de ejemplo hasta que sus salidas coincidan bien con los ejemplos.
Inference (inferencia)
Usar un modelo entrenado para hacer predicciones sobre datos nuevos; también se llama inferencing o scoring.
Rule-based software (software basado en reglas)
Software cuyo comportamiento proviene de lógica explícita escrita por un desarrollador y no de patrones aprendidos de los datos.
Confidence score (puntuación de confianza)
Un número, a menudo entre 0 y 1, que devuelve un modelo para mostrar qué tan seguro está de una predicción.
Workload (carga de trabajo)
Una categoría de problema que aborda la IA, como visión artificial, NLP o detección de anomalías.
Forecasting (pronóstico)
Predecir valores futuros a lo largo del tiempo, como la demanda diaria, a partir de datos históricos basados en el tiempo.
Anomaly detection (detección de anomalías)
Identificar datos o eventos que difieren significativamente del patrón normal.
Optical character recognition (OCR, reconocimiento óptico de caracteres)
Extraer texto impreso o manuscrito de imágenes y documentos escaneados.
Knowledge mining (minería de conocimiento)
Extraer información de grandes cantidades de contenido no estructurado y hacerla consultable mediante búsqueda.
Generative AI (IA generativa)
IA que crea contenido nuevo, como texto, código o imágenes, a partir de un prompt.
Computer vision (visión artificial)
El área de la IA que interpreta imágenes y video.
Image classification (clasificación de imágenes)
Asignar una o más etiquetas a una imagen en su conjunto, sin ubicar objetos.
Object detection (detección de objetos)
Encontrar objetos en una imagen y devolver una etiqueta y un bounding box para cada uno.
Semantic segmentation (segmentación semántica)
Etiquetar cada píxel de una imagen para conocer el contorno exacto de cada objeto.
Bounding box (cuadro delimitador)
Las coordenadas de un rectángulo que marca dónde aparece un objeto o una palabra en una imagen.
Face verification (verificación facial)
Comprobar si dos imágenes de rostros pertenecen a la misma persona; es una capacidad de Limited Access en Azure AI Face.
Natural language processing (NLP, procesamiento de lenguaje natural)
IA que analiza, entiende y genera lenguaje humano en forma de texto.
Sentiment analysis (análisis de sentimiento)
Determinar si un texto expresa una opinión positiva, negativa, neutral o mixta.
Entity recognition (reconocimiento de entidades)
Encontrar y clasificar elementos de un texto, como personas, lugares, organizaciones, fechas y cantidades.
Speech recognition (reconocimiento de voz)
Convertir audio hablado en texto; también se llama speech to text.
Speech synthesis (síntesis de voz)
Producir audio hablado de sonido natural a partir de texto; también se llama text to speech.
Conversational AI (IA conversacional)
Software como bots y asistentes que interactúa con los usuarios mediante un diálogo natural.
Intent (intención)
El objetivo detrás del mensaje de un usuario en una conversación, como reservar un vuelo o consultar un saldo.
Document intelligence (inteligencia de documentos)
IA que extrae texto, pares clave-valor, tablas y campos con nombre de documentos y los convierte en datos estructurados.
Key-value pair (par clave-valor)
Una etiqueta y su valor encontrados en un documento, como 'Fecha de vencimiento' y '30 de junio'.
Prebuilt model (modelo prediseñado)
Un modelo listo para usar para un tipo de documento común, como facturas o recibos, que no necesita entrenamiento.
Custom model (modelo personalizado)
Un modelo entrenado con un conjunto pequeño de tus propios documentos de muestra etiquetados para extraer campos de tus formularios exclusivos.
Search index (índice de búsqueda)
Un almacén de contenido procesado y campos extraídos que los usuarios o las apps pueden consultar rápidamente.
AI enrichment (enriquecimiento con IA)
Pasos (skills) que se aplican durante la indexación en Azure AI Search y que llaman a servicios de IA para extraer información adicional del contenido.
Prompt
La instrucción, pregunta o contexto que se le da a un modelo de IA generativa para producir una respuesta.
Large language model (LLM, modelo de lenguaje grande)
Una red neuronal muy grande entrenada con texto que genera lenguaje prediciendo tokens.
Token
Una unidad de texto, como una palabra o parte de una palabra, que un modelo de lenguaje lee y genera.
Copilot (copiloto)
Un asistente de IA generativa integrado en una app que ayuda al usuario con tareas mientras el usuario mantiene el control.
Agent (agente)
Una solución de IA generativa que combina un modelo con instrucciones, conocimiento y herramientas para poder realizar acciones hacia un objetivo.
Hallucination (alucinación)
Salida fluida y plausible de un modelo generativo que es incorrecta o no está respaldada por sus fuentes.
Fairness (equidad)
El principio de que la IA debe tratar a todas las personas de forma justa y no dar resultados distintos a personas similares por características irrelevantes.
Reliability and safety (confiabilidad y seguridad)
El principio de que la IA debe funcionar de forma consistente y segura según lo previsto, incluso en condiciones inesperadas.
Bias (sesgo)
Una desviación sistemática en los datos o en el comportamiento del modelo que produce resultados injustos para algunos grupos.
Proxy feature (variable sustituta)
Una característica, como el código postal, que representa indirectamente una característica sensible y puede introducir falta de equidad.
Model drift (deriva del modelo)
Una disminución del rendimiento de un modelo con el tiempo a medida que los datos del mundo real se alejan de los datos de entrenamiento.
Responsible AI dashboard (panel de IA responsable)
Una herramienta de Azure Machine Learning que incluye evaluación de equidad y otras funciones para evaluar modelos de forma responsable.
Privacy and security (privacidad y seguridad)
El principio de que los sistemas de IA deben proteger los datos personales y ser seguros frente al mal uso y los ataques.
Inclusiveness (inclusión)
El principio de que la IA debe empoderar a todos y estar diseñada para que la usen personas de todas las capacidades y orígenes.
Personally identifiable information (PII, información de identificación personal)
Datos que pueden identificar a una persona, como un nombre, número de teléfono, dirección o número de identificación.
Data minimization (minimización de datos)
Recopilar y conservar solo los datos personales que realmente necesita un propósito.
Redaction (censura de datos)
Ocultar o eliminar valores sensibles, como reemplazar un número de cuenta por asteriscos.
Accessibility (accesibilidad)
Diseñar productos para que las personas con discapacidad puedan percibirlos, operarlos y entenderlos, por ejemplo con lectores de pantalla o subtítulos.
Transparency (transparencia)
El principio de que las personas deben entender cómo funciona un sistema de IA, para qué sirve y cuáles son sus limitaciones.
Accountability (rendición de cuentas)
El principio de que las personas que diseñan e implementan sistemas de IA responden por cómo operan.
Explainability (explicabilidad)
Mostrar qué entradas o características influyeron más en la salida de un modelo.
Feature importance (importancia de las características)
Una medida de cuánto contribuye cada característica de entrada a las predicciones de un modelo, usada en las herramientas de interpretabilidad.
Transparency note (nota de transparencia)
Documentación de Microsoft que describe las capacidades, los usos previstos y las limitaciones de un servicio de IA.
AI governance (gobernanza de la IA)
Las políticas, juntas de revisión, responsabilidades y procesos que controlan cómo una organización crea y usa la IA.
Impact assessment (evaluación de impacto)
Una revisión documentada de los usos previstos, las partes interesadas, los daños potenciales y las mitigaciones de un sistema de IA.
Human in the loop (persona en el proceso)
Un diseño en el que una persona revisa o aprueba las salidas de la IA antes de que surtan efecto.
Limited Access (acceso limitado)
La política de Microsoft que exige aprobar al cliente y el caso de uso antes de poder usar funciones de IA sensibles.
Custom neural voice (voz neuronal personalizada)
Una capacidad de Speech que crea una voz sintética parecida a la de una persona específica; es una función de Limited Access.
Responsible AI Standard (estándar de IA responsable)
El marco interno de requisitos de Microsoft que sus equipos siguen al crear sistemas de IA.

Dominio 2: Fundamental principles of machine learning on Azure (19%)

Consejos para el examen

  • Si la pregunta plantea qué columna es la etiqueta, elige el valor que se está prediciendo. Una gran diferencia entre el rendimiento de entrenamiento y el de validación significa sobreajuste. Malos resultados en ambos significan subajuste. En el momento de la inferencia, solo se proporcionan las características.
  • Etiqueta numérica significa regresión. Las métricas con 'error' en el nombre deben ser bajas; el R² debe estar cerca de 1. Si el RMSE es mucho mayor que el MAE, unas pocas predicciones están muy equivocadas. Precision y recall nunca son métricas de regresión.
  • Dos clases es binaria; más de dos es multiclase, aunque las clases sean números como calificaciones del 1 al 5. Si no detectar positivos sale caro: recall. Si las falsas alarmas salen caras: precision. Con datos desbalanceados, no confíes solo en la accuracy.
  • Sin etiquetas y 'descubrir grupos' significa clustering. Categorías conocidas que hay que predecir significa clasificación, aunque el escenario use la palabra 'grupo'. Supervisado: regresión y clasificación. No supervisado: clustering.
  • El deep learning es un subconjunto del machine learning, que es un subconjunto de la IA. Si un escenario trata de imágenes, audio o lenguaje natural a gran escala, la técnica de fondo es el deep learning. El entrenamiento ajusta los pesos para reducir la pérdida.
  • Los tokens son las unidades de texto; los embeddings son los vectores que representan el significado; la atención relaciona los tokens entre sí en su contexto. Los modelos de tipo GPT generan prediciendo el siguiente token. Los servicios cobran por tokens.
  • La compute instance es para el desarrollo de una persona; el compute cluster es para trabajos de entrenamiento escalables y puede reducirse a cero. Azure Machine Learning sirve para entrenar tus propios modelos; Azure AI services te da modelos prediseñados.
  • Probar muchos algoritmos automáticamente y elegir el mejor: AutoML. Construir un pipeline de forma visual conectando componentes: designer. Ninguno requiere escribir código. AutoML sigue necesitando una columna de etiqueta y una métrica principal.
  • Si alguien espera una respuesta inmediata, es un endpoint en tiempo real (online). Si hay que puntuar un gran conjunto de datos de forma programada, es por lotes (batch). Las preguntas sobre encontrar dónde comete más errores un modelo, si trata distinto a ciertos grupos o cómo explicar sus predicciones apuntan al Responsible AI dashboard.

Términos clave

Feature (característica)
Un valor de entrada que usa el modelo para hacer una predicción, como la edad o la superficie.
Label (etiqueta)
El valor que un modelo supervisado se entrena para predecir, como un precio o un resultado sí/no.
Supervised learning (aprendizaje supervisado)
Aprendizaje automático que se entrena con datos que tienen etiquetas conocidas, como la regresión y la clasificación.
Unsupervised learning (aprendizaje no supervisado)
Aprendizaje automático que encuentra estructura en datos sin etiquetas, como el clustering.
Training data (datos de entrenamiento)
La parte de los datos de la que aprende el algoritmo.
Validation data (datos de validación)
Datos reservados del entrenamiento que se usan para medir qué tan bien rinde el modelo con ejemplos no vistos.
Overfitting (sobreajuste)
Cuando un modelo aprende demasiado de cerca los datos de entrenamiento y rinde mal con datos nuevos.
Hyperparameter (hiperparámetro)
Una configuración que se elige antes del entrenamiento y que controla cómo aprende el algoritmo, como la profundidad de un árbol.
Regression (regresión)
Aprendizaje supervisado que predice un valor numérico.
Residual (residuo)
La diferencia entre un valor predicho y el valor real de una observación; también se llama error.
Mean absolute error (MAE, error absoluto medio)
La diferencia absoluta promedio entre los valores predichos y los reales, en las unidades de la etiqueta.
Mean squared error (MSE, error cuadrático medio)
El promedio de los errores al cuadrado; penaliza mucho los errores grandes y está en unidades al cuadrado.
Root mean squared error (RMSE, raíz del error cuadrático medio)
La raíz cuadrada del promedio de los errores al cuadrado; penaliza los errores grandes más que el MAE y está en las unidades de la etiqueta.
Coefficient of determination (R², coeficiente de determinación)
La proporción de la varianza de la etiqueta que explica el modelo; cuanto más cerca de 1, mejor.
Binary classification (clasificación binaria)
Predecir una de dos clases, como sí o no.
Multiclass classification (clasificación multiclase)
Predecir una de tres o más clases, como cuál de cinco equipos debe atender un ticket.
Confusion matrix (matriz de confusión)
Una tabla de clases reales frente a predichas que muestra los verdaderos y falsos positivos y negativos.
Accuracy (exactitud)
La proporción de todas las predicciones que fueron correctas: (TP + TN) / total.
Precision (precisión)
De los elementos predichos como positivos, la proporción que realmente era positiva: TP / (TP + FP).
Recall (exhaustividad)
De los elementos positivos reales, la proporción que encontró el modelo: TP / (TP + FN).
F1 score (puntuación F1)
La media armónica de precision y recall, que es baja si cualquiera de las dos es baja.
Clustering (agrupamiento)
Aprendizaje no supervisado que agrupa elementos con valores de características similares.
k-means
Un algoritmo de clustering que agrupa elementos alrededor de k puntos centrales y ajusta los centros repetidamente.
Centroid (centroide)
El punto central de un cluster, calculado como el promedio de los elementos asignados a él.
Neural network (red neuronal)
Un modelo formado por capas de neuronas artificiales conectadas cuyos pesos se aprenden durante el entrenamiento.
Weight (peso)
Un número en una conexión entre neuronas que se ajusta durante el entrenamiento para reducir el error.
Hidden layer (capa oculta)
Una capa de neuronas entre la capa de entrada y la de salida; muchas capas ocultas hacen que una red sea profunda.
Deep learning (aprendizaje profundo)
Machine learning con redes neuronales que tienen muchas capas ocultas.
Loss function (función de pérdida)
Un cálculo que mide qué tan lejos están las predicciones de un modelo de las respuestas correctas.
Epoch (época)
Una pasada completa por los datos de entrenamiento durante el entrenamiento.
Token
Una unidad de texto, como una palabra o parte de una palabra, que procesa un modelo de lenguaje.
Context window (ventana de contexto)
El número máximo de tokens que un modelo puede manejar en una solicitud, incluidas la entrada y la salida.
Embedding
Un vector de números que representa el significado de un token o texto, donde los significados similares quedan cerca.
Attention (atención)
Un mecanismo que permite a cada token ponderar la relevancia de los demás tokens de la secuencia.
Transformer
Una arquitectura de red neuronal basada en la atención, usada por los modelos de lenguaje modernos.
Decoder model (modelo decodificador)
Un transformer, como GPT, que genera texto prediciendo el siguiente token.
Workspace (área de trabajo)
El recurso de nivel superior de Azure Machine Learning que contiene datos, cómputo, trabajos, modelos y endpoints.
Azure Machine Learning studio
El portal web para trabajar con un workspace de Azure Machine Learning.
Data asset (recurso de datos)
Una referencia con nombre y versión a los datos usados para entrenar, como un archivo o una carpeta en el almacenamiento.
Datastore (almacén de datos)
Una conexión guardada a un servicio de almacenamiento subyacente, a la que apuntan los data assets.
Compute instance (instancia de cómputo)
Una VM de desarrollo administrada para los notebooks y experimentos de un solo usuario.
Compute cluster (clúster de cómputo)
Un grupo de VM que escala automáticamente para trabajos de entrenamiento y puede reducirse a cero cuando está inactivo.
Automated machine learning (AutoML, machine learning automatizado)
Una función que prueba automáticamente muchos algoritmos y configuraciones y ordena los modelos resultantes según una métrica elegida.
Primary metric (métrica principal)
La medida que usa AutoML para ordenar los modelos, como accuracy o RMSE normalizado.
Designer
Un lienzo de arrastrar y soltar en Azure Machine Learning studio para construir pipelines de entrenamiento de forma visual.
Featurization (caracterización)
Preparar los datos en bruto para el entrenamiento, como manejar valores faltantes y codificar categorías.
Pipeline
Una secuencia de pasos conectados, como preparación de datos, entrenamiento, puntuación y evaluación, que se ejecuta como un trabajo.
Data guardrails (protecciones de datos)
Comprobaciones automáticas de AutoML que señalan problemas en los datos, como el desbalance de clases o los valores faltantes.
Endpoint
Una dirección web donde un modelo implementado acepta datos de entrada y devuelve predicciones.
Inference (inferencia)
Usar un modelo entrenado para hacer predicciones sobre datos nuevos.
Online (real-time) endpoint (endpoint en línea o en tiempo real)
Un endpoint que devuelve predicciones de inmediato para solicitudes individuales.
Batch endpoint (endpoint por lotes)
Un endpoint que puntúa grandes volúmenes de datos de forma asíncrona como un trabajo y escribe los resultados en el almacenamiento.
Data drift (deriva de datos)
Un cambio a lo largo del tiempo en los datos que recibe un modelo en comparación con sus datos de entrenamiento, que puede reducir su exactitud.
Responsible AI dashboard (panel de IA responsable)
Una herramienta de Azure Machine Learning que combina análisis de errores, equidad, interpretabilidad, análisis contrafactual what-if y análisis de datos para un modelo.

Dominio 3: Computer vision workloads on Azure (19%)

Consejos para el examen

  • Toda la imagen, una sola respuesta: clasificación. Dónde y cuántos: detección de objetos con bounding boxes. Contorno exacto, píxel por píxel: segmentación. Elige la técnica más simple que cubra la necesidad.
  • Los píxeles son números. Los filtros producen mapas de características. Las CNN aprenden sus filtros durante el entrenamiento en lugar de usar filtros elegidos a mano. Un modelo que puede responder preguntas sobre imágenes o relacionar imágenes con texto es multimodal.
  • Oración que describe la imagen: captions. Varias regiones descritas: dense captions. Lista de palabras clave: tags. Dónde están las cosas: detección de objetos o de personas. Región para una miniatura: smart crops. Texto en la imagen: OCR (Read).
  • Extraer texto de imágenes: OCR con Read. Extraer campos con nombre o tablas de formularios: Document Intelligence. Describir la imagen con palabras: captions, no OCR. El OCR devuelve texto, no significado.
  • Detección y atributos de la imagen como desenfoque, lentes y pose de la cabeza: disponibles. Identificación (uno a muchos) y verificación (uno a uno): Limited Access. Emoción, género y edad: retirados. Si solo hay que contar personas: considera la detección de personas.
  • Documento de negocio común con campos estándar: modelo precompilado. Tablas y estructura de cualquier documento: layout. Solo texto: read. Tu propio formulario único: modelo de extracción personalizado entrenado con muestras etiquetadas, con un modelo de clasificación personalizado para ordenar lotes mezclados.
  • Una clave y un endpoint para muchos servicios, una sola factura: multiservicio. Nivel gratuito F0, facturación separada o un límite de acceso separado para un solo servicio: un solo servicio. Una app necesita el endpoint más una clave (o Entra ID) para llamarlo.
  • Asocia la salida con el servicio: descripción u objetos con el análisis de imágenes de Vision, texto con Read de Vision, campos y tablas con Document Intelligence, rostros con Face, tus propias clases con un modelo personalizado, preguntas libres sobre imágenes con un modelo generativo multimodal.

Términos clave

Image classification (clasificación de imágenes)
Predecir una o más etiquetas para una imagen en su conjunto.
Object detection (detección de objetos)
Ubicar cada objeto de una imagen con una etiqueta de clase, una puntuación de confianza y un bounding box.
Bounding box (cuadro delimitador)
Las coordenadas de un rectángulo dibujado alrededor de un objeto detectado.
Semantic segmentation (segmentación semántica)
Clasificar cada píxel de una imagen para producir una máscara precisa de cada clase.
Instance segmentation (segmentación de instancias)
Segmentación que además separa los objetos individuales de la misma clase.
Confidence score (puntuación de confianza)
Un valor entre 0 y 1 que muestra qué tan seguro está el modelo de una predicción.
Pixel (píxel)
El elemento más pequeño de una imagen digital, almacenado como uno o más valores numéricos.
Channel (canal)
Una de las cuadrículas de valores de una imagen, como el componente rojo, verde o azul de una imagen a color.
Filter (kernel) (filtro)
Una pequeña cuadrícula de pesos que se aplica sobre una imagen para producir un feature map, por ejemplo para resaltar bordes.
Feature map (mapa de características)
La salida de aplicar un filtro a una imagen, que muestra dónde aparece una característica.
Convolutional neural network (CNN, red neuronal convolucional)
Un modelo de deep learning que aprende filtros para extraer características de imágenes en tareas como la clasificación.
Transfer learning (aprendizaje por transferencia)

Dominio 4: Natural language processing workloads on Azure (19%)

Consejos para el examen

  • Ánimo general de un texto: análisis de sentimiento. Ánimo hacia funciones específicas mencionadas: minería de opiniones. Qué idioma: detección de idioma. Ninguna de ellas traduce ni genera texto.
  • Temas principales: frases clave. Menciones clasificadas como personas y fechas: NER. Desambiguar y vincular con Wikipedia: vinculación de entidades. Encontrar y ocultar datos personales: detección de PII.
  • Contar palabras no puede saber que 'auto' y 'automóvil' están relacionados; los embeddings sí. La búsqueda semántica, la similitud, las recomendaciones y el paso de recuperación de RAG apuntan a embeddings.
  • Versión corta de un texto largo: resumen (el extractivo elige oraciones, el abstractivo escribe nuevas, el resumen de conversaciones maneja transcripciones). Tus propias categorías: clasificación de texto personalizada entrenada con ejemplos etiquetados.
  • Siempre revisa la dirección: los subtítulos y las transcripciones son speech to text; leer texto en voz alta es text to speech. Custom speech corrige el reconocimiento de palabras especiales; SSML da forma a la voz sintetizada; custom neural voice necesita aprobación de Limited Access.
  • Texto o documentos: Azure AI Translator (la traducción de documentos conserva el formato). Audio hablado: traducción de voz de Azure AI Speech. Convertir sistemas de escritura sin cambiar el significado: transliteración.
  • En 'Pide dos pizzas grandes', la oración completa es el enunciado, OrderPizza es la intención, y 'dos' y 'grandes' son entidades. CLU devuelve la intención y las entidades estructuradas, no una respuesta.
  • Contenido de FAQ existente y 'responder preguntas comunes' apuntan a question answering. 'Entender qué quiere hacer el usuario y extraer detalles' apunta a la comprensión del lenguaje conversacional.
  • Análisis de texto: Language. Audio: Speech. Otro idioma: Translator, salvo que la entrada sea hablada; entonces, traducción de voz. Acción a partir de un comando: CLU. Respuesta a partir de FAQ: question answering. Varias necesidades: asocia cada una y luego encadénalas en orden.

Dominio 5: Generative AI workloads on Azure (24%)

Consejos para el examen

  • Los LLM predicen tokens; no buscan respuestas almacenadas. Todo lo relacionado con límites del conocimiento, fechas de corte o datos inventados se remonta a esto, y la solución habitual es el grounding con tus propios datos.
  • Crear, redactar, reescribir o conversar libremente: IA generativa. Extraer un campo específico o asignar una etiqueta fija de forma confiable: un servicio de IA tradicional puede ser la mejor respuesta. Ayuda dentro de una app existente: copiloto. Realiza acciones: agente.
  • El rol, las reglas y el formato que se aplican a toda la conversación van en el mensaje de sistema. Los ejemplos dentro del prompt son few-shot. Cambiar los pesos del modelo es fine-tuning, no ingeniería de prompts.
  • El modelo debe responder a partir de tus datos actuales o privados sin reentrenarlo: RAG. El modelo debe adoptar un estilo o formato de forma consistente: el fine-tuning puede ayudar. RAG primero recupera y luego genera.
  • Necesitas una salida repetible y factual: baja la temperatura. Necesitas variedad creativa: súbela. Respuestas cortadas a mitad de oración: max tokens es demasiado bajo. Ajusta temperature o top_p, no ambos.
  • Comparar y elegir modelos: catálogo de modelos. Probar prompts y parámetros sin código: playground. Organizar los recursos y el acceso del equipo de una solución: proyecto. Espera ver tanto el nombre Azure AI Foundry como Microsoft Foundry.
  • Vectores para búsqueda y RAG: modelo de embeddings. Conversación y generación de texto: modelo de chat GPT. Imágenes a partir de texto: modelo de generación de imágenes. Azure OpenAI se cobra y no tiene nivel gratuito.
  • Solo responde preguntas: asistente de chat o copiloto. Usa herramientas para realizar acciones o completar tareas de varios pasos: agente. Los agentes necesitan herramientas con mínimo privilegio y aprobación humana para las acciones de alto impacto.
  • Memoriza el orden: identificar, medir, mitigar, operar. La mitigación tiene cuatro capas: modelo, sistema de seguridad, mensaje de sistema y grounding, experiencia de usuario. Los filtros de contenido cubren odio, contenido sexual, violencia y autolesiones.
  • Respaldada por las fuentes: groundedness. Responde la pregunta: relevancia. Se lee de forma natural: fluidez. Organizada de forma lógica: coherencia. Intentar romperla deliberadamente: red teaming.

Términos clave

Large language model (LLM, modelo de lenguaje grande)
Un modelo transformer muy grande entrenado con cantidades masivas de texto que genera lenguaje prediciendo tokens.
Token
Una unidad de texto con la que trabaja el modelo, como una palabra, una parte de palabra o un signo de puntuación.
Next-token prediction (predicción del siguiente token)
Generar texto prediciendo repetidamente un siguiente token probable y agregándolo.
Pretraining (preentrenamiento)
El entrenamiento autosupervisado inicial con grandes colecciones de texto que le enseña a un modelo patrones del lenguaje y conocimiento.
Context window (ventana de contexto)
El número máximo de tokens que un modelo puede manejar en una solicitud, incluidos el prompt y la respuesta.
Hallucination (alucinación)
Salida fluida pero falsa o sin respaldo que un modelo produce cuando genera texto plausible sin la información correcta.
Small language model (SLM, modelo de lenguaje pequeño)
Un modelo de lenguaje más pequeño, barato y rápido, con una capacidad más limitada, que a veces puede ejecutarse en dispositivos.
Chat assistant (asistente de chat)
Una app de IA generativa que conversa con los usuarios en lenguaje natural durante varios turnos.
Copilot (copiloto)
Un asistente de IA generativa integrado en una app para ayudar a los usuarios con tareas mientras ellos mantienen el control.
Summarization (resumen)
Condensar contenido largo en una versión más corta que conserva los puntos clave.
Code generation (generación de código)
Usar un modelo para escribir, explicar o convertir código a partir de descripciones en lenguaje natural.
Multimodal model (modelo multimodal)
Un modelo que puede aceptar más de un tipo de entrada, como texto e imágenes.
Agent (agente)
Una aplicación de IA generativa que usa herramientas para realizar acciones y completar tareas de varios pasos.
System message (mensaje de sistema)
Instrucciones enviadas antes de la conversación que definen el rol, las reglas, el tono y el formato de salida del modelo.
User prompt (prompt de usuario)
La solicitud o pregunta del usuario enviada al modelo.
Few-shot prompting
Incluir en el prompt algunos ejemplos de entrada y de la salida deseada para que el modelo siga el patrón.
Zero-shot prompting
Darle al modelo solo una instrucción, sin ejemplos.
One-shot prompting
Darle al modelo un solo ejemplo de entrada y de la salida deseada junto con la instrucción.
Delimiter (delimitador)
Marcadores, como comillas triples o encabezados, que separan las instrucciones del contenido que el modelo debe procesar.
Grounding (fundamentación)
Proporcionar información relevante y confiable en el prompt para que el modelo base su respuesta en ella.
Retrieval augmented generation (RAG, generación aumentada por recuperación)
Un patrón que recupera contenido relevante de tus datos y lo agrega al prompt antes de que el modelo genere una respuesta.
Chunking (fragmentación)
Dividir los documentos en pasajes más pequeños para poder indexar y recuperar las partes más relevantes.
Embedding
Un vector de números que representa el significado de un texto para que el contenido similar se pueda encontrar por similitud.
Vector index (índice vectorial)
Un índice de búsqueda que almacena embeddings para que el contenido pueda recuperarse por similitud semántica.
Hybrid search (búsqueda híbrida)
Combinar la búsqueda por palabras clave con la búsqueda vectorial para encontrar contenido relevante.
Fine-tuning (ajuste fino)
Entrenar más un modelo preentrenado con tus propios ejemplos para cambiar su comportamiento o su estilo.
Temperature (temperatura)
Un parámetro que controla la aleatoriedad en la selección de tokens; baja es enfocada y consistente, alta es variada y creativa.
Top_p
Un parámetro que limita las opciones de tokens al conjunto más probable cuya probabilidad combinada llega a p; también se llama nucleus sampling.
Max tokens (máximo de tokens)
Un límite al número de tokens que el modelo puede generar en una respuesta.
Stop sequence (secuencia de parada)
Texto que le indica al modelo que deje de generar cuando lo produce.
Parameter (parámetro de la solicitud)
Un valor enviado con una solicitud que cambia cómo el modelo genera la salida sin cambiar el modelo en sí.
